개인정보 처리방침

시행일 2026-10-19 · 적용 대상: bridge.creco.dev 웹 서비스와 iOS 앱 Agent Bridge

Agent Bridge(이하 "서비스")의 운영자(이하 "운영자")는 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

요약. 서비스는 정보주체의 맥에서 실행되는 Claude Code 세션을 휴대전화와 웹에서 이어서 보고 조작하게 하는 도구입니다. 세션은 언제나 정보주체의 맥에서 실행되며, 대화의 원본도 맥에 있습니다. 서버는 세션의 대화를 저장하지 않고 맥과 휴대전화·웹 사이에서 전달만 하며, 계정 정보와 세션 목록에 필요한 정보(제목, 상태 등)만 저장합니다. 광고·분석·원격 측정 도구는 사용하지 않으며, 개인정보를 판매하거나 광고에 이용하지 않습니다.

Agent Bridge 는 Anthropic 과 무관한 독립 프로젝트입니다. Claude 는 Anthropic 의 상표입니다.

제1조(개인정보의 처리 목적)

운영자는 다음 목적을 위하여 개인정보를 처리합니다. 처리하는 개인정보는 다음 목적 외의 용도로는 이용하지 않으며, 이용 목적이 변경되는 경우에는 「개인정보 보호법」 제18조에 따라 필요한 조치를 이행합니다.

  1. 회원 가입 및 관리: GitHub 또는 Apple 계정으로 로그인, 로그인 유지, 화면 표시, 다른 계정이 이름을 바꾸어 들어오는 것의 방지, 운영자의 접근 승인
  2. 서비스 제공: 연결한 맥의 목록 표시, 세션을 실행할 계정의 선택, 세션 대화의 표시와 전달, 사용자가 고른 설정의 적용, 보낸 그림·영상의 맥 전달
  3. 알림: 알림 목록, 웹 푸시 알림, iOS 앱 알림
  4. 민원 처리 및 서비스 개선: 문제 제보의 처리, 연결 문제의 진단
  5. 부정 이용 방지: 지나친 요청의 제한

② 세션의 대화는 서버에 저장하지 않습니다. 보낸 글, Claude 의 답, 도구 호출과 결과, 화면 기록, 대화의 그림과 보낸 그림은 정보주체의 맥(Claude Code 대화 파일과 에이전트의 화면 기록)에 있으며, 서버는 맥과 휴대전화·웹 사이에서 전달만 합니다. 전달을 위하여 세션마다 최근 기록 일부(최대 1,000개)와 그림 일부를 서버의 메모리에 잠시 두며, 세션을 다른 맥으로 옮기는 동안에는 그 대화를 메모리에 둡니다. 메모리의 정보는 디스크에 쓰지 않고 서버를 다시 시작하면 사라집니다. Slack 플러그인으로 보내는 대화도 메모리를 거쳐 전달만 합니다.

③ 서비스 이용 과정에서 다음 정보가 자동으로 생성되어 처리됩니다.

  1. IP 주소: 지나친 요청을 막기 위하여 메모리에만 두며(공개 데모는 1시간, 그 밖은 1분) 저장하지 않습니다. 서버 실행 로그에도 남기지 않습니다.
  2. 서버 실행 로그: 로그인 이름, 맥 이름, 화면 오류 메시지가 남습니다. 맥 로그의 내용, 요청 주소의 쿼리, 작업 폴더 경로, 원격 저장소 주소의 인증 정보는 남기지 않습니다.

④ 정보주체의 기기(브라우저·앱)에 저장하는 정보는 제11조에 적습니다.

⑤ 개인정보는 정보주체가 GitHub 또는 Apple 로 로그인하거나, 맥을 연결하거나, 서비스를 이용하는 과정에서 수집합니다.

제3조(개인정보의 처리 및 보유 기간)

운영자는 다음 기간 동안 개인정보를 처리·보유하며, 기간이 지나면 지체 없이 파기합니다.

  1. 끝난 세션: 세션이 끝난 날부터 7일 뒤 세션 정보를 서버에서 삭제합니다. 정보주체가 세션을 지우면 즉시 삭제합니다. 이때 맥이 연결되어 있으면 맥의 에이전트에 둔 그 세션의 화면 기록도 함께 지웁니다.
  2. 로그인 토큰: 30일 동안 유효합니다. 만료된 토큰의 해시는 1시간 안에 삭제합니다.
  3. 보낸 영상: 맥이 받으면 바로 삭제하고, 받지 못한 영상도 24시간 뒤 삭제합니다.
  4. 알림: 30일 동안 최근 30개까지 보관하고 그 뒤 자동으로 삭제합니다. 세션을 지우면 그 세션의 알림도 삭제합니다.
  5. 웹 푸시 구독: 알림을 끄거나 푸시 서비스가 구독 종료를 알리면 삭제합니다.
  6. 앱 알림 토큰: 앱에서 알림을 끄거나 로그아웃하거나, Apple 이 토큰이 더 이상 쓰이지 않는다고 알리면 삭제합니다.
  7. 호스트 로그: 맥마다 약 10 MB 까지만 보관하고 오래된 것부터 삭제합니다.
  8. 문제 제보: 제보 글·그림·영상·진단 정보는 처리를 위하여 90일 동안 보관하고 자동으로 삭제합니다. 제보는 문제 해결을 위하여 운영자가 사용하는 AI 도구로 처리될 수 있습니다. 계정을 삭제하여도 그 기간 동안 남습니다. 그 전에 "지난 제보"에서 직접 삭제할 수 있습니다.
  9. 접근 요청 기록(대기·거절): 마지막 시도로부터 90일 뒤 삭제합니다.
  10. 데모: 데모에서 만든 세션과 설정은 24시간 동안 쓰지 않으면 삭제합니다.
  11. 그 밖의 정보(계정 정보, 허용된 접근 기록, 호스트, 설정): 자동으로 삭제하지 않으며, 회원 탈퇴(계정 삭제) 시 삭제합니다.
  12. 이전에 저장된 대화: 2026년 10월 18일 이전 판에서 서버에 저장된 대화 사본·화면 기록·그림은 맥으로 옮긴 뒤 2026년 10월 19일 서버에서 모두 삭제하였습니다.
  13. 이름 고정 기록: 계정을 삭제한 뒤에도 보관합니다(제4조 ③).

제4조(개인정보의 파기 절차 및 방법)

① 파기 절차: 운영자는 보유 기간이 지났거나 처리 목적이 달성된 개인정보를 제3조의 기준에 따라 자동으로 또는 정보주체의 요청에 따라 파기합니다.

② 파기 방법: 개인정보는 서버의 전자적 파일 형태로만 저장하며, 파기할 때에는 서버의 파일에서 삭제합니다. 종이 문서로 출력하여 보관하는 개인정보는 없습니다.

  1. 화면에서 직접 삭제: 세션 "지우기"·"목록에서 지우기", 그룹 "모두 지우기", 알림 "지우기"·"모두 지우기", 푸시 알림 끄기, 플러그인 "빼기", 내 제보 "지우기".
  2. 계정 삭제: 앱(웹)의 설정 → 더 보기 → 계정 삭제에서 로그인 이름(Apple 로 로그인한 경우 "삭제")을 입력하면 즉시 삭제합니다. Apple 로 로그인한 계정은 Apple 에 토큰 취소도 요청합니다. 계정 정보, 접근 요청 기록, 모든 기기의 로그인, 세션 정보·영상(이전 판에서 저장된 대화 사본·화면 기록·그림 포함), 설정·프롬프트·그룹, 알림, 웹 푸시 구독과 앱 알림 토큰, 플러그인 설정과 Slack 연결, 연결한 맥 기록과 연동이 서버에서 삭제되며(문제 제보는 위 보관 기간 동안 남습니다), 맥의 연동 탭·에이전트는 더 이상 이 서버에 연결되지 않습니다. 직접 삭제할 수 없는 경우 제12조의 연락처로 GitHub 로그인 이름과 함께 요청할 수 있습니다.

③ 계정을 삭제하여도 이름 고정 기록(로그인 이름과 GitHub 숫자 id 한 줄)은 보관합니다. 허용 목록이 이름으로 정해져 있으므로, 다른 GitHub 계정이 그 이름으로 바꾸어 들어오는 것을 막기 위함입니다. 같은 GitHub 계정으로 다시 로그인하면 빈 새 계정으로 시작합니다.

④ 정보주체의 맥에 있는 Claude Code 대화 파일과 작업 폴더는 서비스가 삭제하지 않으며, 정보주체가 맥에서 직접 관리합니다. 맥의 에이전트가 둔 화면 기록(~/.claude-bridge/events/)은 맥이 연결된 동안 세션을 지우면 함께 지우며, 그 밖에 남은 것(계정 삭제 뒤 포함)은 정보주체가 맥에서 직접 지울 수 있습니다.

제5조(개인정보의 제3자 제공)

① 운영자는 개인정보를 제1조의 목적 범위에서만 처리하며, 정보주체의 개인정보를 제3자에게 제공하지 않습니다. 개인정보를 판매하거나 광고에 이용하지 않습니다.

② 다만 정보주체가 Slack 플러그인을 직접 켠 경우에 한하여, 정보주체 자신의 Slack 앱으로 세션 제목·맥 이름·작업 폴더·대화를 보냅니다. 이 전송은 제7조에 적습니다.

제6조(개인정보 처리의 위탁)

① 운영자는 개인정보 처리 업무를 위탁하지 않습니다.

② 서버와 데이터는 운영자가 관리하는 서버에 있습니다. 데이터베이스나 외부 저장소 서비스는 사용하지 않고 그 서버의 파일로만 저장합니다.

제7조(개인정보의 국외 이전)

① 운영자는 다음과 같이 개인정보를 국외로 이전합니다(「개인정보 보호법」 제28조의8). 국가는 이전받는 자의 본사 소재지이며, 실제 처리 서버의 위치는 이전받는 자가 정합니다.

제10조(개인정보의 안전성 확보 조치)

운영자는 개인정보의 안전성 확보를 위하여 다음 조치를 하고 있습니다.

  1. 접근 통제: 운영자가 허용한 계정만 서비스를 이용할 수 있으며, 허용 전에 로그인한 계정은 운영자의 승인을 기다립니다.
  2. 인증 정보의 보호: 로그인 토큰은 원래 값이 아닌 해시(SHA-256)로만 저장합니다. GitHub 접근 토큰은 저장하지 않으며, Apple 계정 번호는 그대로 두지 않고 해시로 바꾸어 계정 이름을 만듭니다.
  3. 쿠키 보호: 로그인 쿠키는 HttpOnly·SameSite=Lax 이며, HTTPS 로 접속한 경우 Secure 로 설정합니다.
  4. 전송 구간 보호: 서비스는 HTTPS 로 제공합니다.
  5. 요청 수 제한: 로그인·제보·잠금 해제 등의 지나친 요청을 IP 주소마다 1분 단위로 제한합니다.
  6. 저장 파일의 접근 제한: 데이터 파일과 폴더는 서버 실행 계정만 읽고 쓸 수 있는 권한(0600·0700)으로 만듭니다.
  7. 보안 머리글: 콘텐츠 보안 정책(CSP), X-Content-Type-Options: nosniff, Referrer-Policy: no-referrer 를 적용합니다.

제11조(개인정보 자동 수집 장치의 설치·운영 및 거부)

① 운영자는 로그인 유지를 위하여 다음 쿠키를 사용합니다. 모두 HttpOnly 입니다.

  2. cb_state: GitHub 로그인 중 확인용, 10분
  3. cb_apple: Apple 로그인 중 확인용, 10분

② 브라우저 저장소에는 목록과 최근 세션 대화의 사본(빠른 표시용), 작성 중인 글, 화면·아이콘·음성 설정, 최근 받아쓰기 결과를 저장합니다. 이 정보는 해당 기기에만 있으며 서버로 보내지 않습니다.

③ iOS 앱은 웹 화면을 띄우는 앱입니다. 위의 웹 저장소 외에는 따로 정보를 수집하거나 저장하지 않으며, 분석 도구를 사용하지 않습니다. 마이크와 음성 인식 권한은 받아쓰기를 사용할 때에만 사용합니다.

④ 광고·분석·행태정보 수집을 위한 쿠키나 도구는 사용하지 않습니다.

⑤ 거부 방법: 정보주체는 브라우저 설정에서 쿠키 저장을 거부하거나 삭제할 수 있습니다. 다만 쿠키를 거부하면 로그인이 필요한 서비스를 이용할 수 없습니다.

Privacy Policy (English summary)

Effective 2026-10-19 · Applies to the bridge.creco.dev web service and the Agent Bridge iOS app. The Korean text above is the full policy.

Agent Bridge lets you watch and drive the Claude Code sessions running on your own Mac from a phone or the web. The server does not store your conversations: it only relays them between your Mac and your devices. It is an independent project, not affiliated with Anthropic. Claude is a trademark of Anthropic.

Controller and contact

The person who operates this server, Jeong Seokho (정석호), is responsible for the data it stores and is the privacy officer. Questions and access or deletion requests: nodejsdeveloper@kakao.com.

What is stored

  • Your GitHub login, numeric id, display name and avatar URL; a hash of your sign-in token and its expiry.
  • With Sign in with Apple (iOS app): an account name made from your Apple user id, the name Apple gives at the first sign-in (or your e-mail, Apple's relay address if you hid it), and a refresh token kept only to revoke it when you delete your account.
  • Access requests (accounts that signed in before being approved: name, avatar, first/last attempt, number of attempts, the deciding operator).
  • The Macs you connect: name, type, home folder path, last seen, agent/Node/OS versions, and the sign-in method of the Claude accounts signed in on that Mac (their e-mail and plan are kept in memory only while the Mac is connected).
  • Sessions: title, an 80-character preview, status, the Mac, working folder, PR links found in the conversation and usage numbers. A locked session keeps neither title nor preview (unless you named it). The conversation itself (messages, replies, tool calls and results, screen log, pictures) stays on your Mac; the server keeps only the latest part of it in memory to relay it (up to 1,000 entries per session), never on disk, and gone when the server restarts. Conversations stored by earlier versions were moved to your Mac and deleted from the server on 2026-10-19.
  • Settings (groups, default prompt, voice settings and term list, plugin settings such as a Slack bot token), notifications, web push subscription endpoints, the iOS app's notification token, videos you send, problem reports, and host logs (which never contain message text).
  • IP addresses are kept only in memory for rate limiting (one hour for the public demo, one minute otherwise) and are not stored, not even in the server log. The server log holds login names, Mac names and page error messages, never Mac log text, request queries, folder paths or credentials in git remote addresses.
  • On your device: a sign-in cookie (30 days), sign-in state cookies (10 minutes), and a local cache of lists, recent conversations, drafts and settings. The iOS app collects nothing else and has no analytics; it uses the microphone and speech recognition only for dictation.

Retention and deletion

  • Ended sessions are deleted 7 days after they end, or at once when you delete them (together with the agent's screen log on your Mac, if it is connected). Videos: as soon as your Mac has them, 24 hours at most. Expired sign-in token hashes: within an hour. Notifications: 30 days (latest 30). Host logs: about 10 MB per Mac. Problem reports (text, pictures, videos, diagnostics): 90 days, even if you delete your account. Waiting or refused access requests: 90 days after the last attempt. Demo sessions and settings: deleted after 24 hours unused. Sign-in tokens are valid for 30 days.
  • Your account, access record, Macs and settings are not deleted automatically. Delete your account in the app under Settings → 더 보기 (More) → 계정 삭제 (Delete account) by typing your login name (or 삭제 if you signed in with Apple): everything above is removed from the server at once, every sign-in ends, and your Macs' bridge can no longer connect. You can also email the contact above with your GitHub login.
  • After deletion one line is kept: your login name and its GitHub numeric id, so that another GitHub account cannot take over the name the allow-list knows. Signing in again with the same GitHub account starts a new, empty account.
  • Files on your own Mac (Claude Code conversations, working folders) are not touched.

Third parties and transfers abroad

  • No data is given to third parties, and no processing is outsourced.
  • GitHub (USA) for sign-in (login, id, name and avatar only; no GitHub access token is stored).
  • Apple (USA) for Sign in with Apple in the iOS app (user id, name, e-mail or relay address). Deleting your account asks Apple to revoke the app's token.
  • Anthropic: sessions are run by Claude Code on your Mac with your own Anthropic account; your prompts reach Anthropic through Claude Code under Anthropic's terms. This server sends no session content to Anthropic. Problem reports may be processed with an AI tool the operator uses to fix the problem.
  • Voice dictation: the recording goes through this server only to your own Mac running the session, where whisper.cpp turns it into text on the Mac. The recording does not leave your Mac: it is not sent to any outside AI service, and the server passes it on without storing it.
  • Apple (and Google) (USA): live dictation uses the browser's speech recognition, which may go through Apple's or Google's servers (can be turned off in Settings → Voice). Web push goes through the browser's push service with no content; the device fetches the notification text from this server. Notifications in the iOS app go through Apple's push service (APNs) and carry the device token, the notice title (the session name, up to 80 characters), one line of text (up to 200 characters) and the session id; a locked session's notice says only that there is something to check.
  • Slack (USA): only if you turn on the Slack plugin, to your own Slack app.
  • Hosting: data is stored as files on a server the operator manages; no external database or storage service.

Your rights and security

You may ask to see, correct or delete your data, or to stop its processing, in the app or by email. Sign-in tokens are stored only as hashes, cookies are HttpOnly, the service is served over HTTPS, only accounts the operator approves can use it, requests are rate-limited, and data files are readable only by the server. No data is sold or used for advertising. There are no ads, analytics or telemetry. The service is a developer tool and is not directed at children. You can also contact the Korean Personal Information Dispute Mediation Committee (1833-6972) or the Personal Information Infringement Report Center (118).
