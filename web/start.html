Agent Bridge 시작 가이드

맥의 Claude Code 를
폰에서도, 다른 맥에서도

맥에서 도는 진짜 Claude Code 터미널 세션을 웹으로 이어 줍니다. 권한 요청에 폰으로 답하고, 하던 세션을 다른 맥으로 옮기고, 원하면 Slack 에서도 이어서 씁니다.

처음 시작하기

GitHub 계정으로 로그인합니다. 로그인하면 지금 어디까지 했는지 저절로 체크되는 단계별 가이드가 열려요.

📱 폰으로 답하기"이 명령 실행해도 될까요?" 를 폰 알림으로 받고 바로 답해요. 맥 앞에 없어도 일이 멈추지 않아요.
💻 맥 사이 옮기기맥북에서 하던 세션을 맥 미니로. 대화와 폴더를 그대로 가져가요.
💬 Slack 은 원할 때만세션 메뉴에서 Slack 으로 보내고, 스레드의 버튼으로 다시 가져와요. 한 번에 한 곳에서만 작업해서 엇갈리지 않아요.
🔁 재부팅해도 이어서맥이 다시 켜지면 쉬던 세션을 같은 대화로 다시 열어요.

준비물

  • macOS 맥 한 대 이상, 그 맥의 Chrome
  • 그 맥에서 로그인해 둔 Claude Code (claude 가 터미널에서 실행돼야 해요)
  • GitHub 계정 (이 사이트 로그인용)
  • Slack 도 쓰려면: 앱을 만들 수 있는 Slack 워크스페이스

처음 시작하기 · 약 5분

  1. 로그인GitHub 로 로그인해요. 운영자가 허락해야 하는 서버면 승인을 기다리는 안내가 나와요.
  2. 맥 연결맥의 터미널에 설치 명령 한 줄을 붙여 넣어요. 가이드 화면에 그 명령이 복사 버튼과 함께 있어요.
  3. 맥의 Chrome 에 이 사이트 열어 두기열린 탭이 맥과 서버를 이어요. "로컬 네트워크의 기기에 연결" 을 물으면 허용해요.
  4. 첫 세션 띄우기+ 를 눌러 맥과 폴더를 고르고 첫 메시지를 보내요. 이제 폰에서도 같은 세션이 보여요.

자주 묻는 것

Slack 앱 만드는 것도 해 주나요?

가이드에 "AI 에게 Slack 쪽 준비 맡기기" 프롬프트가 있어요. 브라우저를 다루는 AI 에게 주면 앱 만들기와 전용 채널 만들기, 봇 초대까지 해요. 토큰은 AI 가 다루지 않게 해 두었어요. 토큰 두 개를 붙여 넣는 것만 직접 해요.

맥이 꺼지거나 잠들면요?

세션은 맥에서 돌기 때문에 멈춰요. 기기 화면에서 "잠자기 막기" 를 켤 수 있고, 맥이 다시 켜지면 쉬던 세션을 다시 열어요.
