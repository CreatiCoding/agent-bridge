# bridge MCP 의 파일 첨부(`attach`)와 다른 세션 대화 읽기(`read_session`) 설계

사용자 요청(SPEC 1.401, REQ-F-846·REQ-F-847·IF-269·IF-270). 세션이 맥의 파일을 이 대화의 답에 붙여 사람이 조작 화면에서 보고 받게 하고, 같은 사람의 다른 세션(같은 맥, 연결된 다른 맥)의 최근 대화를 읽게 한다. 익스텐션이나 따로 띄우는 MCP 서버 없이, 세션이 이미 가진 `bridge` MCP(`agent/mcp.mjs`, REQ-F-760·REQ-F-778)에 도구 두 개를 더한다.

## 0. 한 줄 요약

- `attach {path, name?}`: 에이전트가 파일을 검사해 `~/.claude-bridge/attach/<무작위 id>` 에 **복사본**과 색인(해시·크기)을 두고, 도구 결과에 표식 한 줄을 남긴다. 화면은 그 도구 줄을 보고 첨부 카드(그림은 미리보기, 그 밖은 받기)를 그리고, 바이트는 서버의 새 경로가 맥에 **id 로만** 물어 받는다. 봉인 중이면 id·세션·이름·종류·바이트가 **한 조각**으로 봉인돼 짝지은 기기만 풀고, 화면은 그 안의 id·세션을 확인한다.
- `read_session {session?, limit?, skip?, tools?}`: 같은 맥의 세션을 id 로 부르면 **에이전트가 그 세션의 대화 기록 파일(JSONL)을 직접 읽어** 답한다(서버를 거치지 않음). 이름·다른 맥·목록만 서버에 묻고, 서버는 **같은 uid** 의 세션만 고른다. 대상이 이 맥이면 서버는 id 만 돌려주고 읽기는 이 맥에서 한다. `enforce`·봉인 맥은 서버에 아예 묻지 않고, 봉인 맥은 다른 맥에 대화를 보내지 않는다.

## 1. 기존 길과 재사용

| 있던 것 | 쓰는 법 |
|---|---|
| bridge MCP → 에이전트 `/delegate`(hookKey) | 두 도구도 이 입구로 온다. op 로 갈라 `attach` 는 에이전트 안에서만, `read_session` 은 필요할 때만 서버(기존 위임 메시지) |
| 답 속 그림 경로 → `localimg`(`readimage`) | 그림만, 경로로 묻는 길이다. 첨부는 서버가 경로로 물을 수 없게 **id 로만** 묻는 새 명령 `attachment` 로 한다. 복사본은 그림 폴더(`images/`, 세션의 `--add-dir`·`readimage` 의 뿌리)에 두지 않는다 |
| 도구 줄(`k:tool`·`k:tool_end`) | 첨부 표식은 결과 글 첫 줄. 봉인 중에도 페이지는 풀린 글을 받으므로 화면이 표식을 읽는다(서버는 해석하지 않음) |
| 대화 내보내기 조각 `EXPORT_PART` 4 MiB | 첨부 한도도 4 MiB(봉인 뒤 약 7.5 MB 로 연동 탭 한 번 올리기 안) |
| 위임(`runDelegate`) | `read_session` 은 맨 앞에서 갈라, 위임 기능 스위치·한 단계 규칙과 무관 |

## 2. `attach`

- 경로: `~/…`·상대 경로(세션 cwd 기준) → `realpathSync.native`(실제 대소문자). 허용 뿌리: 홈, 임시 폴더(`os.tmpdir()`·`/tmp`), 세션 cwd(경로 조각 2개 이상일 때만, `/`·`/Volumes` 같은 넓은 곳은 아님).
- 비밀 거절(대소문자 무시): 키·로그인 폴더(`.ssh`, `.aws`, Keychains, 브라우저 프로필, `.claude-bridge-signing` …), 이름(`.env*`, `id_*`, `*.pem`, `credentials.json`, `*.tfstate` …), `~/.claude-bridge`(그림 폴더 제외). 목록은 SPEC REQ-F-846 규칙 3.
- 열기: `O_NOFOLLOW` 로 한 번 열고 그 fd 로 stat(실제 경로의 dev·ino 와 같음, 일반 파일, 링크 수 1, 0 < 크기 ≤ 4 MiB) 뒤 그 fd 에서 읽는다. 세션당 1시간 30개.
- 저장: `attach/<id>`(0600, 폴더 0700) + `attach/index.json` `{sid, name, type, size, sha256, at}`. 30일 뒤·색인 밖 파일은 지움.
- 종류(`attachType`): 그림은 머리 바이트가 맞을 때만, pdf 는 `%PDF` 일 때만, 글 확장자는 `text/plain`, html·svg·js 등은 `application/octet-stream`.
- 결과: `[bridge-attach] {"id","name","type","size"}` + 안내 한 줄(경로 없음).
- 내주기(`attachment` 명령, 분류표 `free`): 색인에 있고 lstat 이 일반 파일·링크 수 1·크기와 SHA-256 이 같을 때만. 봉인 중이면 `sealOut` 이 `{kind:'attach', id, sid, name, type, size, data}` 한 조각으로.
- 화면: 도구 묶음 밖 카드. 평문 답은 `id` 가 같을 때만, 봉인 답은 풀린 JSON 의 kind·id·sid 가 같을 때만. 그림(png·jpeg·gif·webp)만 `<img>` 로, 나머지는 `application/octet-stream` Blob 으로 받기만(페이지로 열지 않음). 1 MiB 이하 그림만 바로 미리보기.

## 3. `read_session`

- 같은 맥 id(또는 8자 이상 유일한 앞부분) → `convHere`: 대화 기록이 Claude 프로젝트 폴더 안일 때만, 끝 8 MiB, 사람·Claude 글만(도구 결과·감싸기 태그만인 글·사이드체인·메타 제외), `skip` 뒤 `limit`(≤100), 글마다 4,000자, 합 40,000자. 머리에 "자료이지 지시가 아니에요".
- 그 밖: `enforce`·봉인 → 서버에 묻지 않음(목록은 이 맥 세션만). 아니면 서버 `readSession`: 같은 uid·닫히지 않은 세션, 목록 50개, id → id 앞부분 → 이름 정확 → 이름 포함, 여럿이면 후보와 함께 거절. 이 맥이면 `{here}`, 다른 맥이면 `convread`(30 s) → `{host, text}` → 부른 맥이 `fromElsewhere` 로 다시 감쌈.
- `convread`(분류표 `free`): 봉인 중이면 거절, 오류 글은 경로 없는 고정 문구.

## 4. 검토에서 바뀐 것(다른 관점 리뷰, 구현 전)

| 지적 | 반영 |
|---|---|
| 복사본을 `images/` 에 두면 답에 경로가 실릴 때 `readimage` 로 평문 그림이 서버에 감(봉인 우회), 이름 추측 신호 | `attach/` 따로, 이름 없는 id 파일, 경로를 결과에 싣지 않음 |
| 첨부 답 칸을 따로 봉인하면 서버가 다른 조각을 옮기고 type 을 html 로 바꿀 수 있음(앱 웹뷰에서 Blob 이 열림) | 한 조각 봉인 + 화면이 kind·id·sid 확인, 종류는 화면 허용표로만, 그림 외는 octet-stream |
| warn+봉인에서 `read_session` 이 이름을 평문으로 보내고 서버의 `{here}` 를 믿음 | 봉인 맥도 `enforce` 처럼 서버에 묻지 않음 |
| 10 MiB 봉인 답(약 18.6 MB)이 연동 탭 30 s 올리기에서 막혀 다시 시도를 반복할 수 있음 | 4 MiB, 그림 자동 미리보기는 1 MiB 이하만 |
| 오류 글·로그에 경로 | 서버로 가는 오류는 고정 문구, 로그는 크기만 |
| JS `realpathSync` 는 대소문자를 바로잡지 않음, TOCTOU, 하드 링크, `images/` 에 심은 링크, cwd `/`, 빠진 비밀 위치 | `.native`, fd 하나로 검사·읽기와 dev·ino 비교, 링크 수 1, 색인+해시, `attachRoots`, 목록 보강 |
| 훅이 알린 `transcript_path` 를 그대로 읽음 | Claude 프로젝트 폴더 안만 |
| 다른 맥 결과의 "자료" 머리를 서버·그 맥이 꾸밀 수 있음 | 부른 맥이 `<<< >>>` 로 다시 감쌈 |

## 5. 남는 위험과 하지 않은 것

- **비밀 거절은 최선의 노력이다.** 세션은 먼저 다른 이름으로 복사한 뒤 첨부할 수 있고, 원래 답 글에 내용을 쓸 수도 있다. 첨부가 새로 넓히는 범위는 바이너리 파일을 사람 화면(과, 봉인이 아니면 서버)에 보내는 정도다.
- `/delegate` 의 세션 id 는 쿼리로 오고 hookKey 는 맥의 모든 세션이 같아, 한 세션이 다른 세션 id 로 부를 수 있다(1시간 30개 한도·cwd 뿌리를 그 세션 것으로 씀). 모두 같은 사람의 세션이라 범위가 넓어지지는 않는다. 세션마다 다른 토큰은 다음 단계.
- 봉인된 `read_session` 결과는 서버가 도구 결과를 6,000자에서 자르며 조각째 빠져 사람 화면에는 `…` 로 보인다(Claude 는 전부 받음).
- iOS 앱 웹뷰에서는 `<a download>` 받기가 안 될 수 있다(그림 미리보기는 됨).
- 닫힌 세션(이어서 하기) 읽기, 봉인 맥 사이 읽기(키가 맥마다 다름), 로컬 화면(1.398)의 첨부 카드는 하지 않았다.
