# 명세와 아직 다른 것

예전 Slack 기반 도구의 명세·코드와 조항별로 대조해 찾은 차이 중 **아직 고치지 않은 것**. 고친 것은 `docs/LESSONS.md` 10절과 커밋 기록에 있다.

## 동작

- **명령과 응답 시간**: 복제·새 세션은 맥이 끝낼 때까지 기다렸다 답한다(보통 30초 안). 가벼운 복제는 바로 답하고 결과를 나중에 알린다.
- **백그라운드 작업 목록**: Monitor 만료와 셸 수 상한은 넣었다. "프로세스 시작 뒤에 시작한 것만" 은 새로고침·다시 열기 때 목록을 비우는 것으로 대신한다.

## 넣었지만 실제로 확인하지 못한 것

- Slack 플러그인을 실제 워크스페이스에 붙이는 것(가짜 Slack 으로만 테스트).

실제로 돌려 확인한 것(2026-10-05): 실제 PR 의 PR 창·PR 칩·언급된 PR, 통계의 PR 블록, 복수 선택 질문, 플랜 승인 화면, 예전 에이전트의 자동 업데이트. 백그라운드 명령 둘 중 끝난 하나가 다음 턴 전에 목록에서 빠지는 것도 확인했다. 다만 그때 빠진 것이 셸 수 상한 때문인지 완료 알림 때문인지는 가려 보지 않았다.

## 일부러 다른 것

- 세션이 사는 맥이 여러 대다: 목록의 기기 구역, 다른 맥으로 옮기기·이어 열기.
- 맥이 꺼져 있으면 보낼 수 없다(서버는 사본과 중계만 한다).
- 화면 캡처는 PNG 가 아니라 SVG.
- 알림 센터에 결정 카드와 5·10분 다시 알리기를 넣는다(Slack DM 이 없어서).
- Slack 은 핵심이 아니라 사용자별 플러그인.
- 끝난 세션을 목록 끝에 10개 남기거나 지난 기록(archives)으로 보관하지 않는다. 여기서 `ended` 행은 "맥에서 멈췄지만 끝내지는 않은 세션" 이고, 끝낸 세션은 모두 "이어서 하기" 에 있으며 그 자리에서 대화를 읽을 수 있다.
