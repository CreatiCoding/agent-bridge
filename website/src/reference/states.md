# 세션 상태와 카드

이 페이지는 화면에 보이는 세션 상태, 세션과 호스트(맥)의 상태 전이, **카드**(터미널 확인 창을 대신하는 결정 요청)의 종류를 정리해요. 세션을 다루는 방법은 [폰에서 세션 다루기](/guide/use/sessions)를, 상태가 왜 이렇게 나뉘는지는 [세션의 일생](/guide/concepts/sessions)을 보세요.

이 페이지는 SPEC 판 1.309 기준이에요.

| 2 | 다른 맥으로 옮기거나 다시 여는 중이에요. | 옮기는 중 | 보라 | 예 | |
| 3 | 세션의 맥이 연결돼 있지 않아요. | 기기 끊김 | 회색 | | |
| 4 | Claude Code 가 돌고 있지 않아요. | **휴면** 표시가 있으면 "휴면", 아니면 "멈춤" | 회색 | | |
| 5 | 카드가 열려 있거나 사람을 기다려요. | 카드 종류 이름([카드 종류](#카드-종류)), 모르면 "응답 대기" | 노랑 | | 예 |

## 에이전트가 보는 세션 단계

에이전트는 맥에서 세션마다 단계(phase)를 계산해 서버에 알려요. 판정 순서가 우선순위예요.

| 단계 | 뜻 | 들어가는 때 | 나가는 때 |
|---|---|---|---|
| `ended` | Claude Code 가 도는 터미널이 없어요. 목록에는 남아요. | 터미널이 사라진 것을 확인했을 때 | 새로고침·다시 열기·되살리기로 다시 띄우면 `starting` |
| `starting` | Claude Code 가 뜨는 중이에요. 시작 확인 창이 떠 있을 수 있어요. | 세션을 띄웠을 때 | 시작 훅이나 화면이 쉬는 모양이면 `idle`, 턴이 시작되면 `busy` |
| `waiting` | 사람의 결정이 필요해요. | 카드가 열렸을 때, 같은 확인 창이 되풀이될 때, 작업이 중단된 채 멈췄을 때 | 카드가 접히면 턴이 있으면 `busy`, 없으면 `idle` |
| `busy` | 턴이 도는 중이에요. | 글을 넣었을 때, 도구를 쓰기 시작할 때 | 턴이 끝나면(Stop 훅, 또는 빈 입력칸이 15초 동안 보이면) `idle` |
| `idle` | 입력을 기다리며 쉬어요. | 위 어디에도 해당하지 않을 때 | 턴이 시작되면 `busy`, 카드가 열리면 `waiting` |

뜨는 중인 세션이 90,000 ms(90초) 뒤에도 뜨는 중이면 알림 글을 한 번 남겨요.

## 서버가 보는 세션 수명

| 상태 | 뜻 | 다음 상태 |
|---|---|---|
| 시작 | 서버가 세션을 만들고 에이전트의 보고를 기다려요. | 살아 있음, 멈춤, 지워짐(에이전트가 띄우지 못했을 때) |
| 살아 있음 | Claude Code 가 그 맥에서 돌아요(마지막 보고 기준). | 멈춤, 옮기는 중, 끝남, 지워짐 |
| 멈춤 | 끝내지는 않았지만 돌고 있지 않아요. | 살아 있음, 옮기는 중, 끝남, 지워짐 |
| 옮기는 중 | 옮기기·다시 열기·이어 열기가 진행 중이에요. 이 동안 끝내기·지우기·다른 옮기기는 거절해요. | 성공하면 살아 있음, 실패하면 이전 상태 |
| 끝남 | 사람이 끝냈어요. 이어 열 수 있어요. | 옮기는 중(이어 열기), 지워짐 |
| 지워짐 | 목록에서 지웠어요. | — |

멈춘 세션에 글을 보내면 서버가 같은 맥에서 자동으로 다시 열어요(그 맥이 연결돼 있을 때). 다른 맥으로 옮기려면 보내는 맥이 연결돼 있어야 해요. 보내는 맥이 꺼져 있으면 옮길 수 없어요. **휴면**과 **잠금**은 이 상태와 겹쳐 붙는 표시라서 상태를 바꾸지 않아요.

## 호스트 상태

| 상태 | 기기 화면 표시 | 뜻 | 들어가는 때 |
|---|---|---|---|
| 끊김 | `끊김 · N분 전` | 서버에 맥 기록은 있지만 연동 페이지가 붙어 있지 않아요. | 연동 페이지 탭이 닫히거나, 네트워크가 끊기거나, 접근이 회수됐을 때 |
| 연결됨 | `연결됨 · N ms` | 연동 페이지가 붙어 있고 에이전트가 상태를 보내요. 숫자는 왕복 시간이에요. | 연동 페이지가 붙었을 때, 응답 없음 상태에서 에이전트가 다시 상태를 보냈을 때 |
| 응답 없음 | `응답 없음` | 연동 페이지는 붙어 있는데 에이전트가 50,000 ms 넘게 상태를 보내지 않았어요. | 15,000 ms 마다 하는 판정에서 조용한 시간이 50,000 ms 를 넘었을 때 |

맥이 끊기면 서버는 그 맥 세션의 열린 카드와 쓰는 중인 글 표시를 지워요. 세션 화면은 "맥 연결 끊김" 띠를 보이고 이 기기에 남은 대화만 보여 줘요. 조작 페이지는 서버와의 연결이 8,000 ms 넘게 끊기면 화면 위에 끊김 띠를 보여요.

## 카드 종류

| 종류 | 화면 이름 | 언제 생기나요 | 답하는 방법 |
|---|---|---|---|
| `permission` | 권한 요청 | Claude Code 가 도구를 써도 되는지 물을 때(`Do you want to …`) | 허용, 이 세션 동안 허용, 항상 허용, 거부 버튼 가운데 하나를 눌러요. **전부 허용**을 켜면 에이전트가 "이 세션 동안 허용", 없으면 "허용"을 스스로 골라요. |
| `question` | 질문 | Claude 가 선택지로 질문할 때 | 선택지를 고르거나(여러 개 고르기면 고른 뒤 확정), 글로 답해요. 글로 답하면 카드는 "메시지로 답함"으로 접혀요. |
| `plan` | 플랜 승인 | Claude 가 플랜을 보여 주고 진행해도 되는지 물을 때 | 선택지를 고르거나 글로 답해요. |
| `dialog` | 터미널 확인 | 그 밖의 번호 선택 확인 창 | 번호 선택지를 골라요. 같은 창이 900,000 ms 안에 세 번째 뜨면 다시 묻지 않고 한 번 설명해요. |
| `keyed` | 터미널 확인 | 번호 없이 키로 고르는 확인 창 | 화면의 선택지를 골라요. 에이전트가 커서 키와 Enter 로 눌러요. |
| `stuck` | 지시 대기 | 작업이 중단된 채(`Interrupted · What should Claude do instead?`) 다음 지시를 기다릴 때 | 새 지시를 쓰거나 계속하라고 보내요. 버튼은 없어요. |

### 카드가 접히는 때

| 사건 | 카드에 남는 결과 |
|---|---|
| 버튼으로 답함 | `허용`·`이 세션 동안 허용`·`항상 허용`·`거부` 또는 `선택: <고른 것>` |
| 새 턴이 시작됨 | `넘어감 (새 턴이 시작됐습니다)` |
| 글로 답함(질문·플랜·터미널 확인) | `메시지로 답함` |
| 다른 확인 창이 뜸 | `다른 확인 창으로 넘어감` |
| 맥의 터미널에서 직접 답함 | `터미널에서 답함` |
| Esc 를 누름, 또는 중단 | `취소함 (Esc)` |
| 답하려는데 창이 이미 닫힘 | `확인 창이 이미 닫혔습니다` 또는 `이미 닫힌 창` |
| 세션이 끝남 | `세션이 끝남` |
| 전부 허용을 켬 | `전부 허용으로 넘김` |
| 중단 문구가 사라짐(지시 대기) | `이어서 진행` |

전부 허용이 스스로 답한 권한 요청은 열린 카드 없이 "자동 허용" 한 줄로만 남아요.

### 다시 알리기

답하지 않은 카드는 열린 뒤 300,000 ms(5분)에 한 번 다시 알려요. 권한 요청은 600,000 ms(10분)에 한 번 더 알려요. 카드가 접히면 그 알림도 지워요. 알림을 켜는 방법은 [알림과 웹 푸시](/guide/use/notifications)를 보세요.

## 에이전트가 스스로 넘기는 확인 창

아래 창은 카드로 묻지 않고 에이전트가 정해진 선택지를 눌러 넘겨요. 세션이 뜨는 중일 때만 네 가지를 모두 넘기고, 그 밖에는 `/model` 을 넣은 뒤 30,000 ms 안의 모델 전환 창만 넘겨요. 도구 권한 창(`Do you want to …`)은 절대 넘기지 않아요.

| 이름 | 창 | 고르는 선택지 |
|---|---|---|
| `folder-trust` | 이 폴더의 파일을 믿는지 묻는 창(`trust this folder`) | `Yes, I trust` 또는 `Yes, proceed` |
| `dev-channels` | 로컬 개발용인지 묻는 창(`I am using this for local development`) | `I am using this for local development` |
| `model-switch` | 모델을 바꿀지 묻는 창(`Switch model?`) | `Yes, switch` |
| `chrome-extension` | Claude in Chrome 확장을 찾았다는 창 | `No, keep browser tools off` |

뜨는 중이 아닐 때 넘기면 대화에 "↩️ 터미널 확인 창(이름)을 자동으로 넘겼습니다" 한 줄이 남아요. 프로젝트 `.mcp.json` 의 MCP 서버를 쓸지 묻는 창은 넘기지 않고 카드로 물어요.

## 붙잡은 글

도구가 도는 동안 보낸 글은 바로 넣지 않고 **붙잡은 글**로 둬요.

| 상태 | 뜻 | 다음 |
|---|---|---|
| 붙잡음 | 맥의 `sessions.json` 에 저장돼 기다려요. 에이전트가 다시 시작해도 남아요. | 넣을 때가 되면 모두 이어 붙여 한 번에 넣어요. "지금 보내기"로 바로 넣거나 거둘 수 있어요. |
| 전달됨 | 터미널에 넣었어요. | — |
| 버림 | 사람이 거뒀어요. | 넣지 않아요. |
| 잃음 | 세션이 끝나거나 붙여 넣기에 실패했어요. | 대화에 알림이 남아요. |

새 세션의 첫 지시가 8,000 byte 를 넘으면 명령줄에 싣지 않고 붙잡은 글로 뒀다가 Claude Code 가 뜬 뒤 넣어요.
