# 시작하기

이 가이드를 마치면 맥 한 대를 서버에 연결하고, 폰에서 새 세션을 띄워 첫 답을 받을 수 있어요. 순서는 로그인 → 맥에 에이전트 설치 → 맥의 Chrome 에 탭 열어 두기 → 폰에서 세션 시작이에요.

내부 구조는 다루지 않아요. 구조가 궁금하면 [구성과 연결](/guide/concepts/architecture)을 보세요.

## 시작하기 전에

- **돌고 있는 Agent Bridge 서버.** 아래에서 `SITE` 는 서버 주소예요(예: `https://bridge.example.com`). 서버가 없으면 [서버 올리기](/guide/operate/self-host)부터 하세요.
- **GitHub 계정.** 서버 운영자가 허용한 계정만 들어갈 수 있어요.
- **macOS 맥 한 대.** Node.js 18 이상, git, [Claude Code](https://docs.claude.com/en/docs/claude-code)(`claude`)가 필요하고, `claude` 는 로그인돼 있어야 해요. Ubuntu 같은 systemd Linux 서버도 호스트로 붙일 수 있어요([Linux 서버 연결하기](/guide/use/linux)).
- **맥의 Google Chrome.** 맥과 서버를 잇는 탭은 Chrome 에서 열어요.
- **폰 브라우저.** iOS·iPadOS Safari 16.4 이상, Android Chrome 111 이상이에요.

버전 전체는 [지원 환경](/guide/requirements)을 보세요.

::: tip 서버 안의 시작 가이드
로그인한 뒤 `SITE/guide` 를 열면 같은 단계를 화면에서 따라갈 수 있어요. 맥이 연결되거나 세션이 생기면 그 단계가 저절로 체크돼요.
:::

## 1. GitHub 로 로그인하세요

1. 맥의 Chrome 에서 `SITE` 를 여세요.
2. GitHub 로그인 버튼을 누르고 GitHub 에서 허락하세요.
3. 세션 목록이 있는 **조작 페이지**가 열리면 다음 단계로 가세요.

"승인을 기다리는 중이에요" 페이지가 보이면, 그 계정은 아직 허용되지 않은 것이에요. 사용 요청은 서버 운영자에게 전달돼요. 승인되어도 알림은 가지 않으니, 운영자에게 승인을 받은 뒤 다시 GitHub 로 로그인하세요. 운영자 쪽 절차는 [접근 관리와 운영 화면](/guide/operate/admin)을 보세요.

## 2. 맥에 에이전트를 설치하세요

맥의 터미널에서 다음 명령을 한 번 실행하세요.

```sh [터미널]
curl -fsSL SITE/install.sh | bash
```

설치 스크립트는 이 순서로 일해요.

1. macOS 나 Linux 인지 확인해요. 다른 운영체제면 멈춰요.
2. 필요한 도구를 확인해요: `node`, `tmux`, `git`, `claude`. 없는 도구는 [Homebrew](https://brew.sh) 가 있으면 설치할지 물어요. `claude` 는 직접 설치하도록 안내해요.
3. `node` 가 없거나 18 보다 낮으면 멈춰요.
4. 에이전트 파일을 받아 `~/.claude-bridge/` 에 둬요.
5. 처음이면 이 맥의 종류(아이맥, 맥북 등)와 사이트에 보일 이름을 물어요. 그냥 Enter 를 누르면 감지한 값을 써요.
6. 에이전트를 [launchd](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html) 백그라운드 서비스로 설치해요(Linux 는 systemd 사용자 서비스). 맥에 로그인하면 에이전트가 저절로 켜져요.
7. 브라우저로 **연동 페이지**(`SITE/bridge`)를 열어요.

`백그라운드 서비스로 설치했습니다. 이 터미널은 닫아도 됩니다.` 가 보이면 설치가 끝난 것이에요.

`tmux` 는 없어도 돼요. 세션은 에이전트가 직접 받아 두는 [zeropty](https://github.com/CreatiCoding/zeropty) 에서 돌고, `tmux` 는 그게 안 될 때의 대비예요. 단 x86_64 가 아닌 Linux 에는 zeropty 가 없어 `tmux` 가 꼭 있어야 해요.

Linux 서버는 설치 뒤 화면 없이 연결하는 단계가 더 있어요. [Linux 서버 연결하기](/guide/use/linux)를 따라 하세요.

::: warning 아직 없는 도구
끝에 `아직 없는 도구:` 가 찍혀도 에이전트는 켜져요. 그 도구를 설치하기 전에는 세션을 시작할 수 없어요. 설치한 뒤에는 에이전트를 다시 켜지 않아도 바로 돼요.
:::

### 설치 옵션

`bash -s --` 뒤에 옵션을 붙이면 묻지 않고 정할 수 있어요.

```sh [터미널]
curl -fsSL SITE/install.sh | bash -s -- --kind macbook --name "작업 맥북"
```

| 옵션 | 뜻 |
|---|---|
| `--kind <종류>` | 기기 종류. `imac`, `macbook`, `macmini`, `macstudio`, `server`, `other` 중 하나예요 |
| `--name <이름>` | 사이트에 보일 이 맥의 이름이에요 |
| `--no-open` | 끝난 뒤 브라우저를 열지 않아요 |
| `--foreground` | 백그라운드 서비스 대신 이 터미널에서 에이전트를 돌려요 |

옵션 전체는 [설치 스크립트와 에이전트 명령](/reference/agent-cli)을 보세요.

## 3. 맥의 Chrome 에 사이트 탭을 열어 두세요

에이전트는 혼자서는 서버에 연결하지 않아요. 맥의 브라우저에 열린 사이트 탭이 에이전트와 서버를 이어요.

1. 설치 스크립트가 연 연동 페이지가 Chrome 인지 확인하세요. 기본 브라우저가 Safari 면 Safari 로 열려요. 그때는 다음 명령으로 연동 링크를 다시 받아 Chrome 주소창에 붙여 넣으세요.

   ```sh [터미널]
   node ~/.claude-bridge/agent.mjs link
   ```

2. Chrome 이 "로컬 네트워크의 기기에 연결" 을 허용할지 물으면 **허용**을 누르세요. 이 맥의 에이전트(`127.0.0.1`)에 붙는 데 필요해요.
3. 로그인돼 있지 않으면 GitHub 로그인으로 갔다가 연동 페이지로 돌아와요.
4. 연동 페이지에 이 맥의 이름과 로그인한 계정이 보이면 연결된 것이에요.

이 탭을 닫지 마세요. 같은 Chrome 에 조작 페이지(`SITE`) 탭이 열려 있어도 그 탭이 대신 이어요. 사이트 탭을 모두 닫으면 그 맥은 끊겨요. 탭 없이 늘 연결해 두려면 [맥을 늘 연결해 두기](/guide/use/always-on)를 보세요.

## 4. 폰에서 사이트를 여세요

둘 중 하나를 고르세요.

- **폰에서 직접 로그인:** 폰 브라우저에서 `SITE` 를 열고 GitHub 로 로그인하세요.
- **QR 로 로그인:** 맥의 조작 페이지에서 기기 화면(`SITE/hosts`)을 열고 **QR 만들기**를 누르세요. 폰 카메라로 QR 을 찍으면 폰이 같은 계정으로 로그인돼요. QR 은 5분 동안만 쓸 수 있고, 만료되면 **새 QR** 을 누르세요.

폰 브라우저의 "홈 화면에 추가" 로 앱처럼 쓸 수 있어요. iPhone 에서 웹 푸시를 받으려면 홈 화면에 추가해야 해요.

## 5. 새 세션을 시작하세요

1. 조작 페이지에서 **+**(새 세션)를 누르세요.
2. **기기**에서 방금 연결한 맥을 고르세요.
3. **폴더**는 그대로 두세요. 기본값은 `~/bridge/works/<그룹>/<월일>-<id>` 모양의 새 폴더이고, 에이전트가 만들어요. 이미 있는 프로젝트에서 시작하려면 폴더 칸을 눌러 고르세요.
4. **첫 메시지**에 할 일을 적으세요. 예: `이 폴더에 README.md 를 만들고 오늘 날짜를 적어 줘`.
5. **시작**을 누르세요.

세션 화면이 열리고 상태가 **뜨는 중**으로 보여요.

## 6. 메시지를 주고받으세요

1. Claude 가 답을 쓰는 동안 상태는 **작업 중**이고, 지금 쓰는 중인 글이 미리 보여요.
2. 파일을 쓰려는 등 권한이 필요하면 화면에 **카드**가 떠요. 고른 답은 맥의 터미널에 그대로 전해져요.
3. 답이 끝나면 상태가 **대기**로 바뀌어요. 입력칸에 다음 메시지를 적고 보내기 버튼을 누르세요. 폰에서는 Enter 가 줄바꿈이에요.

작업 중에 보낸 메시지는 바로 들어가지 않고 **붙잡은 글**로 기다렸다가, 도구나 턴이 끝나면 전해져요.

## 확인하기

다음이 모두 보이면 성공이에요.

- 폰의 세션 목록에 새 세션이 있고, 상태가 **대기**예요.
- 세션 화면에 첫 메시지와 Claude 의 답이 있어요.
- 기기 화면(`SITE/hosts`)에서 이 맥이 연결됨으로 보여요.
- 맥에서 `node ~/.claude-bridge/agent.mjs service status` 를 실행하면 `서비스: 설치됨, 켜져 있음` 과 `에이전트: 127.0.0.1:<포트> 에서 응답함` 이 찍혀요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 연동 페이지에 "Safari 는 이 페이지가 맥의 에이전트(127.0.0.1)에 붙는 것을 막을 수 있습니다" | 3단계처럼 `link` 명령으로 받은 주소를 Chrome 에서 여세요 |
| "브라우저가 이 사이트의 로컬 네트워크 접근을 막고 있습니다" | 주소창 왼쪽의 사이트 설정에서 "로컬 네트워크 접근" 을 허용으로 바꾸고 새로고침하세요 |
| "이 사이트의 다른 탭이 연동 중" | 정상이에요. 같은 Chrome 의 다른 탭이 잇고 있어요. 그 탭이 닫히면 이 탭이 이어받아요 |
| 새 세션 화면에 "연결된 맥이 없어요" | 맥의 Chrome 에 사이트 탭이 열려 있는지 확인하세요 |
| 세션이 시작되지 않고 도구가 없다는 오류 | 맥에서 `node ~/.claude-bridge/agent.mjs doctor` 로 무엇이 없는지 확인하세요 |

더 많은 경우는 [문제 해결](/guide/operate/troubleshooting)을 보세요.
