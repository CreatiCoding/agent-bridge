# 음성 입력

이 가이드를 마치면 세션 화면에서 말로 메시지를 보낼 수 있어요. 받아쓰기는 세션이 도는 맥에서 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 로 해요. 녹음은 그 맥으로만 가요.

## 시작하기 전에

- 세션이 도는 **호스트(맥)** 에 [Homebrew](https://brew.sh) 가 있어야 해요. 받아쓰기 도구는 맥마다 한 번 깔아요.
- 모델 파일을 받을 디스크 공간이 필요해요. 기본 모델은 574MB 예요.
- 마이크를 쓸 수 있는 브라우저가 필요해요.

## 1. 맥에 whisper.cpp 깔기

세션이 도는 맥의 터미널에서 실행하세요.

```sh [터미널]
brew install whisper-cpp
```

`whisper-server` 와 `whisper-cli` 가 함께 깔려요.

## 2. 모델 받기

기본 모델 `large-v3-turbo-q5_0` 를 받으세요.

```sh [터미널]
mkdir -p ~/.claude-bridge/whisper
curl -L -o ~/.claude-bridge/whisper/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
```

모델은 다섯 가지예요: `large-v3-turbo-q5_0`(기본), `large-v3-turbo`, `medium`, `small`, `base`. 다른 모델을 고르려면 같은 주소에서 `ggml-<모델>.bin` 을 받으세요. 모델이 없는 채로 마이크를 누르면 받을 명령이 담긴 오류가 떠요.

::: details 잡음 줄이기를 RNNoise 로 하려면 (선택)
없으면 내장 방식으로 잡음을 줄여요. RNNoise 를 쓰려면 ffmpeg 와 모델 파일을 두세요.

```sh [터미널]
brew install ffmpeg
curl -L -o ~/.claude-bridge/whisper/rnnoise.rnnn \
  https://raw.githubusercontent.com/GregorR/rnnoise-models/master/somnolent-hogwash-2018-09-01/sh.rnnn
```
:::

## 3. 음성 입력 켜기

1. **설정** → **음성**으로 가세요.
2. **음성 입력** 스위치를 켜세요. 세션 입력창에 마이크 버튼이 생겨요.
3. 필요하면 **언어**, **잡음 줄이기**, **말 다듬기**를 고르세요. 이 값은 계정에 저장돼 모든 기기에 같게 쓰여요.

| 항목 | 기본값 | 설명 |
|---|---|---|
| **언어** | 한국어 | 자동 감지는 더 느리고, 짧은 말에서 언어를 잘못 고를 수 있어요 |
| **잡음 줄이기** | 켬 | 시끄러운 곳에 맞춰요. 조용한 곳에서는 끄는 편이 더 정확할 수 있어요 |
| **말 다듬기** | 켬 | 군말, 되풀이, 문장 부호를 규칙으로 정리해요. 원문은 따로 남아요 |
| 모델 | `large-v3-turbo-q5_0` | 2단계에서 받은 모델과 같아야 해요 |

**이 기기** 칸에서는 이 기기에서만 쓰는 **단축키**, 마이크, **즉시 받아쓰기**를 골라요.

## 4. 말해서 보내기

1. 세션 입력창의 마이크 버튼을 누르세요. PC 에서는 `⌥ Space` 도 돼요(**단축키**에서 `Ctrl ⇧ Space` 로 바꾸거나 끌 수 있어요).
2. **음성 모드**가 켜지면 말하세요. 말을 멈출 때마다 맥이 그 마디를 받아써 판에 쌓아요.
3. **전송**(또는 `Enter`)을 누르면 모인 글이 한 메시지로 가요. 음성 모드는 계속 들어요.
4. 모인 글을 버리려면 **리셋**(또는 `Esc`)을 누르세요.

음성 모드를 끄면 남은 글은 입력창으로 가요.

::: warning 즉시 받아쓰기와 개인정보
**즉시 받아쓰기**는 기본으로 켜져 있어요. 말하는 동안 브라우저의 받아쓰기가 글을 먼저 흐리게 보여 줘요. 이 받아쓰기는 브라우저 회사(Apple·Google)의 서버를 거칠 수 있어요. 녹음을 맥 밖으로 내보내고 싶지 않으면 끄세요.
:::

## 확인하기

마이크 버튼을 누르고 짧게 말해 보세요. **받아쓰는 중…** 뒤에 판에 글이 나타나고, **전송**으로 보낸 글에 세션이 답하면 성공이에요. 처음 한 번은 모델을 읽느라 몇 초 더 걸려요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 이 맥에 whisper.cpp 가 없어요 | 1단계를 세션이 도는 맥에서 하세요 |
| **음성 모델이 맥에 없어요** | 2단계로 고른 모델의 `ggml-<모델>.bin` 을 받으세요 |
| 받아쓴 글이 이상해요 | 맥의 `~/.claude-bridge/voice.log` 나 **설정** → **음성** → **최근 결과**에서 원문과 다듬은 글을 비교하세요. 조용한 곳이면 **잡음 줄이기**를 꺼 보세요 |
| 폰에서 마이크가 끊겨요 | 폰(특히 iOS)은 즉시 받아쓰기가 마이크를 가져갈 수 있어요. 그러면 즉시 받아쓰기가 저절로 꺼져요 |

단축키는 세션 화면 안에서만 들어요. 다른 앱 위에서 쓰는 전역 단축키는 없어요.
