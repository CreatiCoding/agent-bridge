# 기기 상태와 디스크 관리

이 가이드를 마치면 내 기기가 얼마나 바쁜지, 배터리가 얼마나 남았는지 폰에서 보고, 디스크가 찼을 때 그 자리에서 공간을 비울 수 있어요. 기기를 늘 연결해 두는 방법은 [맥을 늘 연결해 두기](/guide/use/always-on)를 보세요.

## 시작하기 전에

- **기기**(호스트)는 에이전트가 설치된 맥이나 Linux 서버예요. [시작하기](/guide/getting-started)를 마쳐 한 대 이상 연결돼 있어야 해요.
- 지금 값은 기기가 연결돼 있을 때만 보여요. 에이전트가 15초마다 보내는 상태 보고에 실려 와요.
- 디스크 정리는 그 기기의 **주인만** 할 수 있어요. 운영자도 주인이 허락하기 전에는 못 해요.

## 1. 기기 상태 보기

1. **설정** → **더 보기** → **기기**로 가세요.
2. 기기를 누르세요.

기기 화면의 줄에서 이런 값을 봐요.

| 줄 | 보이는 것 |
|---|---|
| **맥** | `CPU 19% (8코어) · 메모리 14.2GB / 16GB (83%) · 디스크 85% (35GB 남음)` 꼴이에요 |
| **배터리** | 잔량, 충전 중·배터리 사용·전원 연결, 남은 시간, 사이클, 최대 용량이에요. 배터리가 없는 기기는 `배터리 없음` 이에요 |

배터리는 기기 목록의 줄에도 보여요. 잔량이 20% 이하인데 전원이 연결돼 있지 않으면 빨갛게 보여요. 끊긴 기기는 마지막으로 받은 값을 보여요.

::: details 값은 어떻게 재나요?
- **CPU**: 앞 보고와 이번 보고 사이의 CPU 사용 시간 차이예요.
- **메모리**: macOS 는 "활성 상태 보기" 와 같은 셈(앱 메모리 + 고정 + 압축)이고, Linux 는 `/proc/meminfo` 의 MemTotal − MemAvailable 이에요.
- **디스크**: 홈 폴더가 있는 볼륨을 `df` 와 같은 셈으로 재요. macOS 는 APFS 컨테이너 전체예요.
- **배터리**: macOS 는 `pmset -g batt`, 사이클·최대 용량은 `ioreg` 로 10분마다 읽어요. Linux 는 `/sys/class/power_supply` 를 읽어요.
- 서버는 이 값을 숫자만 골라 넘겨요. 배터리는 바뀌었을 때, 아니면 10분마다 서버의 기기 기록에 남겨요. 그래서 끊긴 기기도 마지막 값을 보여 줄 수 있어요.
:::

## 2. 디스크 관리 열기

1. **설정** → **더 보기** → **디스크 관리**로 가세요.
2. 내 기기가 디스크가 많이 찬 순서로 보여요. 줄마다 사용률 막대와 남은 공간이 있어요.
3. 정리할 기기를 누르면 그 자리에서 디스크 관리 칸이 펼쳐져요.
4. **비울 수 있는 공간 보기**를 누르세요. 크기를 재는 데 1분쯤 걸려요.

디스크 관리 칸은 세 부분이에요. 아래 3~5단계에서 하나씩 다뤄요.

| 부분 | 하는 일 | 되돌릴 수 있나요 |
|---|---|---|
| **캐시** | 비워도 도구가 다시 만드는 캐시와 휴지통을 비워요 | 캐시는 다시 받으면 돼요. 휴지통 비우기는 되돌릴 수 없어요 |
| **머지된 worktree** | 기본 브랜치에 머지된 git worktree 를 한 번에 지워요 | 커밋은 저장소에 남아요 |
| **큰 폴더** | 홈 폴더를 크기순으로 보고, 고른 것을 휴지통으로 옮겨요 | 휴지통에서 되살릴 수 있어요 |

## 3. 캐시 비우기

캐시 목록에서 항목 옆의 **비우기**를 누르세요. 비운 만큼 늘어난 공간을 알려 줘요.

목록에 나오는 캐시는 정해져 있어요. npm, Yarn, pnpm, Homebrew 내려받기, Go 빌드 캐시, Go 모듈 캐시, pip, Playwright 브라우저, 휴지통이에요. macOS 에는 Xcode 빌드 산출물(DerivedData)과 시뮬레이터 캐시도 있어요. 기기에 없는 캐시는 보이지 않아요.

::: warning 휴지통은 되돌릴 수 없어요
**휴지통** 항목을 비우면 그 안의 것은 되살릴 수 없게 지워져요. 큰 폴더를 휴지통으로 옮긴 뒤에도 공간은 휴지통을 비워야 늘어요.
:::

::: details 휴지통을 비울 권한이 없다고 나와요 (macOS)
macOS 는 휴지통을 보호해요. "휴지통 을 비울 권한이 없어요" 가 나오면 안내대로 **시스템 설정**의 개인정보 보호에서 **전체 디스크 접근 권한**에 `node` 를 더하세요.
:::

## 4. 머지된 worktree 정리하기

`git worktree` 로 만든 작업 폴더는 브랜치를 머지한 뒤에도 남아 디스크를 차지해요.

1. **머지된 worktree** 옆의 **찾기**를 누르세요. 저장소마다 `origin` 을 가져온 뒤 판정해요.
2. 목록에서 **정리할 수 있음**인 줄과 정리하면 확보되는 크기를 확인하세요.
3. **N개 정리**를 누르고 확인하세요.

worktree 마다 그 안에서 일한 세션이 `살아 있음`·`끝남` 으로 보여요. 정리를 막는 것은 살아 있는 세션뿐이에요.

::: details 무엇을 정리할 수 있다고 보나요?
아래가 모두 맞아야 **정리할 수 있음**이에요. 하나라도 어긋나면 그 이유가 줄에 보여요.

| 조건 | 어긋나면 보이는 말 |
|---|---|
| 그 worktree 를 쓰는 살아 있는 세션이 없어요 | `살아 있는 세션이 쓰는 중` |
| `git worktree lock` 으로 잠기지 않았어요 | `잠겨 있음(git worktree lock)` |
| 고친 것이나 새 파일이 없어요 | `고친 것·새 파일이 남아 있음` |
| 커밋이 모두 기본 브랜치에 들어가 있어요 | `기본 브랜치에 머지되지 않음` |
| 최근 1시간 안에 쓰이지 않았어요 | `최근 1시간 안에 쓰임` |

- 찾는 곳은 홈 아래 4단계까지의 git 저장소와 열린 세션의 저장소예요. 점 폴더, `node_modules`, `~/Library`, macOS 가 지키는 폴더 안은 보지 않아요.
- 기본 브랜치는 `origin` 의 HEAD 예요. 없으면 `origin/main`, `origin/master`, `main`, `master` 순서로 찾아요.
- 정리할 때 에이전트가 다시 판정해요. 그다음 `git worktree remove`(강제 없음), `git branch -d`, `git worktree prune` 을 차례로 해요.
- 폴더가 이미 없는 worktree 는 `폴더가 없어 목록에서만 지움` 으로 보여요.
:::

### 정리된 worktree 의 세션

끝난 세션이 쓰던 worktree 를 정리하면, 그 세션 화면에 정리됐다는 줄이 남아요. 그 세션을 다시 열면 같은 경로에 빈 폴더를 만들어 대화를 이어 가요. 세션에게도 worktree 가 정리됐다고 알려 줘요.

시작 폴더에서 worktree 로 들어가 일한 세션도 그 worktree 의 세션으로 잡혀요. 에이전트가 세션이 들어간 지금 폴더를 기억하기 때문이에요.

## 5. 큰 폴더를 휴지통으로 옮기기

1. **큰 폴더** 옆의 **홈 폴더 열기**를 누르세요. 홈 폴더의 항목이 큰 것부터 100개까지 보여요.
2. 폴더를 눌러 안으로 들어가세요. 홈 바로 아래 폴더는 옮길 수 없어요.
3. 옮길 항목 옆의 휴지통 단추를 누르세요.

옮긴 것은 지워지지 않아요. macOS 는 `~/.Trash`, Linux 는 `~/.local/share/Trash` 로 가요. 공간을 늘리려면 3단계의 **휴지통**을 비우세요.

::: details 옮길 수 없는 것
- 홈 폴더 밖, 홈 바로 아래 폴더, 이미 휴지통 안에 있는 것.
- `~/.ssh`, `~/.gnupg`, `~/.aws`, `~/.kube`, `~/.docker`, `~/.config`, `~/.local`, `~/.password-store`, `~/Library` 안. 단 `~/Library/Caches` 안은 돼요.
- macOS 가 지키는 폴더(데스크탑, 문서, 다운로드, 사진, 메일 등)와 그것을 품은 폴더. 이런 폴더는 크기도 재지 않아요.
- 에이전트와 Claude Code 가 쓰는 폴더, 열린 세션의 작업 폴더가 든 폴더.
- 홈 밖이나 지키는 폴더를 가리키는 링크는 열지 않아요.

무엇을 지우고 옮길지는 에이전트가 정해요. 사이트는 캐시 이름이나 홈 안의 경로만 보내요.
:::

## 6. 운영자에게 정리 도움 받기

운영자는 다른 사용자의 기기를 볼 수 없고 정리할 수도 없어요. 주인이 허락하면 그 운영자만 24시간 동안 그 기기의 디스크 관리를 쓸 수 있어요.

**운영자가 할 일**

1. **디스크 관리**의 **다른 사용자 기기 · 운영자** 목록에서 기기를 찾으세요.
2. **정리 권한 요청**을 누르세요.
3. 주인이 허락하면 그 줄을 눌러 디스크 관리 칸을 펼치세요. 그만두려면 **요청 취소**를 누르세요.

**주인이 할 일**

1. **디스크 관리**를 열면 그 기기 아래에 "운영자 ○○ 이 디스크 정리를 도우려고 권한을 요청했어요" 가 보여요.
2. **24시간 허용** 또는 **거절**을 누르세요.
3. 허용한 뒤에도 언제든 **권한 거두기**로 끝낼 수 있어요.

요청, 허용, 거둠, 운영자가 한 정리는 그 기기의 로그에 남아요.

::: details 허용한 운영자가 볼 수 있는 것
허용받은 운영자는 주인과 같은 디스크 관리 칸을 써요. 캐시를 비우고, 머지된 worktree 를 정리하고, 홈 폴더의 항목을 휴지통으로 옮길 수 있어요. 홈 폴더 밖과 macOS 가 지키는 폴더는 열지 않아요. 대화 내용은 보이지 않아요.

허용은 화면에 보인 운영자에게만 가요. 그사이 다른 운영자가 요청을 덮어쓰면 "요청한 운영자가 바뀌었어요. 화면을 새로고침해 다시 확인해 주세요" 로 거절돼요.
:::

## 확인하기

- 기기 화면의 **맥** 줄에 CPU·메모리·디스크 값이 보이면 성공이에요.
- 캐시를 비운 뒤 디스크 관리 머리의 남은 공간이 늘었으면 정리가 된 거예요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| `사용률을 아직 받지 못했어요(에이전트가 1.322 이전)` | 그 기기의 에이전트가 오래됐어요. 자동 업데이트를 기다리거나 설치 명령을 다시 실행하세요 |
| `기기가 연결돼 있을 때 쓸 수 있어요` | 기기를 연결하세요. 디스크 관리는 에이전트에 직접 물어요 |
| 크기가 `크기를 읽지 못함` 이에요 | 2분 안에 크기를 재지 못했거나 읽을 권한이 없어요 |
