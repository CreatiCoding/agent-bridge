# 모델 라우팅

이 가이드를 마치면 bridge 로 여는 세션이 일을 나눠 맡겨요. 메인 세션은 지금 쓰는 모델(보통 Opus)로 판단·조율하고, 상태 확인·코드 위치 찾기·조사 같은 가벼운 일은 그 일에 맞는 모델의 서브에이전트에 맡겨요.

## 왜 쓰나요

Claude Code 의 서브에이전트는 따로 정하지 않으면 메인 세션의 모델을 물려받아요. 메인이 Opus 면 파일 하나 읽는 서브에이전트도 Opus 로 돌아요. 모델 라우팅을 켜면 그런 일을 Haiku·Sonnet 이 맡아서 같은 일을 더 싸고 빠르게 해요.

내 `~/.claude` 파일은 건드리지 않아요. bridge 가 세션을 띄울 때만 설정을 넣어 줘요.

## 켜기

1. **설정 → 새 세션** 탭을 여세요.
2. **모델 라우팅** 상자에서 **모델 라우팅 켜기** 스위치를 켜세요. 바로 저장돼요.
3. 새 세션을 여세요. 켠 뒤 **새로 여는 세션부터** 적용돼요. 이미 떠 있는 세션은 다시 열거나 새로고침할 때 적용돼요.

세션이 라우팅으로 떴는지는 세션 설정 시트 아래의 정보에서 **모델 라우팅 켜짐** 으로 확인할 수 있어요.

## 기본 일꾼

| 이름 | 모델 · effort | 맡는 일 | 도구 |
|---|---|---|---|
| `checker` | haiku · low | 상태·로그·파일 확인(읽기 전용) | Read, Grep, Glob, Bash |
| `Explore` | haiku · medium | 코드 위치 찾기(Claude Code 의 기본 Explore 대신) | Read, Grep, Glob, Bash |
| `researcher` | sonnet · medium | 생활·제품 비교, 사실 찾기 조사 | WebSearch, WebFetch, Read, Grep, Glob, Bash |
| `ops-runner` | sonnet · low | 절차가 정해진 반복 운영, 배포 확인 | Read, Grep, Glob, Bash |
| `doc-writer` | sonnet · medium | 일반 문서·요약 | Read, Grep, Glob, Write, Edit |
| `reviewer` | opus · medium | 코드·보안·설계 리뷰, 리뷰 루프의 검토자 | Read, Grep, Glob, Bash, WebFetch |

일꾼마다 모델과 effort 를 바꿀 수 있어요. **서브에이전트 기본 모델**(기본 sonnet)은 모델을 정하지 않고 부른 서브에이전트(general-purpose 등)가 써요. **기본값으로 되돌리기** 를 누르고 저장하면 위 표로 돌아가요.

읽기 전용 일꾼(checker·Explore·researcher·reviewer)은 쓰기·삭제·재시작·배포·push 를 하지 않아요. 모든 일꾼은 확인한 사실만 짧게, 비밀값은 `***` 로 가려서, 내가 쓰는 언어로 보고해요.

## 메인 세션이 따르는 규칙

라우팅이 켜진 세션의 시스템 프롬프트에 짧은 규칙이 붙어요.

- 메인은 판단·조율하고, 표에 맞는 일은 그 일꾼에 맡겨 결과만 받아요. 다른 맥에 맡길 때는 `delegate` 에 model·effort 를 넣어요.
- **품질 위험이 있는 일은 맡겨도 Opus** 로 해요: 설계·구조 결정(effort high), 원인 모를 디버깅이나 같은 실패 2회, 코드·보안·설계 리뷰와 배포 전 검증, 되돌리기 어려운 운영(보안·인프라 설정 변경, 데이터 삭제, 강제 push, 권한·키), 여러 파일에 걸친 큰 구현, 무인 장기 작업. 애매하면 Opus.
- general-purpose 를 부를 때는 모델을 정해요. 직접 하는 게 더 짧은 일(파일 한두 개, 명령 한 번)과 실시간으로 주고받는 질문은 맡기지 않아요.

## 주의: 이름이 같은 내 서브에이전트

내 `~/.claude/agents` 에 위 표와 **이름이 같은 서브에이전트** 가 있으면, bridge 로 연 세션에서는 라우팅 설정이 그것을 덮어써요(세션 한정 설정이 먼저예요). 내 파일은 바뀌지 않고, 터미널에서 직접 연 Claude Code 에는 영향이 없어요.

## 끄기

**설정 → 새 세션 → 모델 라우팅** 의 스위치를 끄세요. 그 뒤 여는 세션은 라우팅 전과 완전히 같게 떠요(인자·환경변수·프롬프트를 하나도 더하지 않아요). 이미 라우팅으로 떠 있는 세션은 다시 열거나 새로고침할 때 꺼져요.
