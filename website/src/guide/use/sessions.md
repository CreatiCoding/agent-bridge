# 폰에서 세션 다루기

이 가이드를 마치면 폰에서 세션을 띄우고, 글을 보내고, 확인 창에 답하고, 필요할 때 멈출 수 있어요. 세션이 어떤 상태를 거치는지는 [세션의 일생](/guide/concepts/sessions)을 보세요.

## 시작하기 전에

- [시작하기](/guide/getting-started)를 마쳐서 **호스트(맥)** 한 대가 연결돼 있어야 해요. 호스트는 Claude Code 가 실제로 도는 맥이에요.
- **세션**은 호스트에서 도는 Claude Code 하나예요. 폰의 브라우저로 사이트를 열면 세션을 고르고 다루는 **조작 페이지**가 보여요.

## 1. 새 세션 띄우기

1. 목록에서 **새 세션**을 누르세요.
2. **기기**에서 세션을 띄울 맥을 고르세요.
3. **시작 방법**은 **새로 시작**에 두세요. 맥의 대화를 이어 가려면 [맥의 대화 가져오기](/guide/use/adopt)를 보세요.
4. **폴더**에서 작업할 폴더를 눌러 들어가세요. 없는 폴더를 적으면 만들지 물어요.
5. **첫 메시지**에 할 일을 적거나, 비워 두고 세션만 띄우세요. 사진·영상·파일도 **사진·파일 붙이기**로 고르거나, 그 칸에 붙여 넣거나 끌어 놓아 함께 보낼 수 있어요.
6. **시작**을 누르세요.

폴더를 고르지 않으면 새 폴더 `~/bridge/works/<그룹>/<월일>-<id>` 에서 시작해요. 기본 폴더는 **설정** → **새 세션**에서 바꿔요. **모델 · effort · 권한 모드**를 펼치면 이 세션에만 쓸 값을 고를 수 있어요.

## 2. 글과 파일 보내기

입력창에 글을 쓰고 보내세요. 글이 여러 줄이 되면 입력창이 그만큼 커지고, 창 높이의 30% 를 넘으면 그 안에서 스크롤돼요.

사진과 파일은 입력창의 **+**(사진·파일 첨부) → **사진·영상·파일 고르기**로 고르거나, 붙여 넣거나, 끌어 놓아 보내요. 형식은 가리지 않아요.

| 첨부 | 한도 | 맥에서는 |
|---|---|---|
| 그림 | 한 번에 8장, 긴 변 1568px JPEG 로 줄여서 보내요 | 메시지에 그림으로 붙어요 |
| 영상 | mp4·mov·webm·m4v, 하나에 512MB | `~/.claude-bridge/images/` 에 원본 그대로 저장돼요 |
| 그 밖의 파일 | 하나에 512MB | 같은 폴더에 원래 이름으로 저장되고, 메시지에 `[Attached file: <경로>]` 줄이 붙어 Claude 가 읽어요 |

영상과 파일은 합쳐서 한 메시지에 3개까지예요. 대화에는 영상이 "🎬 이름", 파일이 "📎 이름" 으로 남아요.

::: details 첨부의 길과 한도
- 영상과 파일은 먼저 서버에 올리고(`POST /api/sessions/<sid>/upload`), 맥이 받아 가면 서버에서 지워요. 맥이 받지 않은 것은 늦어도 24시간 뒤 지워요(서버 설정 [`retention.uploadsHours`](/reference/config) 의 기본값).
- 한 사람이 서버에 올려 둔 영상·파일은 합쳐 2 GiB 까지예요. 넘으면 "올려 둔 영상·파일이 너무 많아요. 보낸 뒤나 하루 뒤에 다시 올려 주세요" 가 떠요.
- 새 세션에 첨부를 붙이면 세션을 빈 프롬프트로 띄운 뒤 글과 첨부를 한 번에 보내요. 맥은 세션이 뜨는 동안 그 메시지를 붙잡았다가 전해요. 첫 메시지를 보내지 못하면 세션은 그대로 열리고 알림이 떠요.
- 문제 제보에 붙이는 것은 지금도 영상만 돼요.
:::

::: tip 답 안의 선택지 버튼
답 안의 선택지 버튼 글은 끌어서 복사할 수 있어요. 글을 잡은 채 손을 떼면 보내지 않아요. 그냥 누르거나 Enter·Space 를 누르면 그 선택지를 보내요.
:::

### 붙잡은 글

Claude 가 도구를 쓰는 중에 보낸 글은 바로 들어가지 않아요. **붙잡은 글**이 돼서 도구가 끝나면 한꺼번에 전달돼요. 붙잡은 글 묶음 줄에서 다음을 고를 수 있어요.

- **지금 보내기**: 기다리지 않고 바로 넣어요.
- **되돌리기**: 묶음을 입력창으로 되돌려요.

말풍선 메뉴에는 **보내지 않고 되돌리기**와 **잘못 보냄**이 있어요. **잘못 보냄**은 이미 들어간 글을 따르지 말라고 Claude 에게 알려요.

## 3. 확인 창에 답하기

터미널에 뜬 **확인 창**(권한 요청, 질문, 플랜 승인)은 대화에 **카드**로 떠요. 카드에 보이는 명령이나 바뀔 내용을 읽고 버튼을 누르세요. 다른 세션을 보고 있을 때 온 카드는 모달로 떠요.

권한 요청마다 답하기 번거로우면 권한 모드를 바꾸세요. 두 가지가 있어요.

| 권한 모드 | 하는 일 |
|---|---|
| **안전한 전부 허용** | 권한 요청을 에이전트가 바로 허용하고 대화에 남겨요. 위험한 호출만 여전히 물어요 |
| **전부 허용** | 위험한 호출까지 하나도 묻지 않고 바로 허용해요. 빨간색으로 보여요 |

1. 입력창 위의 설정 칩을 누르세요.
2. **세션 설정** → **권한 모드**에서 고르세요.

켜져 있으면 입력창 위에 **안전한 전부 허용** 또는 빨간 **전부 허용 중** 칩이 보여요. 칩을 누르면 꺼져요. **전부 허용**인 세션은 목록의 점에도 빨간 표시가 붙어요. 새 세션의 기본 권한 모드는 **설정** → **새 세션**에서 정해요.

::: danger 전부 허용은 위험한 호출도 묻지 않아요
세션 폴더 밖을 지우는 명령, 강제 push, `sudo`, 비밀 파일 읽기도 바로 실행돼요. 이 세션에서 맡기거나 복제한 세션도 같은 모드를 이어받아요. 꼭 필요할 때만 켜세요.
:::

::: details 안전한 전부 허용이 묻는 위험한 호출
- 세션 폴더 밖을 지우는 명령(`rm -r` 등)
- 원격을 바꾸는 push: `--force`, `--force-with-lease`, `--force-if-includes`, `-f` 가 든 짧은 옵션 묶음(`-fu`), `--mirror`, 원격 브랜치를 지우는 `--delete`·`-d`·`:<브랜치>`·`--prune`, `+<브랜치>`
- `git reset --hard`
- `sudo`. 따옴표 안(`bash -c 'sudo …'`), 백틱, 경로(`/usr/bin/sudo`), `\sudo` 로 써도 sudo 로 읽어요
- 비밀 파일: `~/.ssh`, `.env` 파일, 키체인, 에이전트 설정 파일과 키
- Claude Code 설정(`~/.claude/settings.json`, 훅)과 로그인 때 켜지는 항목(`~/Library/LaunchAgents` 등)

명령은 쓰인 그대로만 읽어요. 실행한 스크립트가 안에서 하는 일은 보지 않아요. 허용한 내용은 대화에 남으니 나중에 확인하세요.

복제, 가벼운 복제, 맡긴 세션, 다른 맥으로 옮기기, 다시 열기는 원래 세션의 권한 모드를 그대로 이어요. 원래 세션이 묻는 모드였다면 복제는 새 세션의 기본값을 따르고, 그 기본값이 전부 허용이면 먼저 물어요.
:::

## 4. 멈추기와 세션 메뉴

- 하던 일을 멈추려면 입력창의 **중단 (Esc)** 버튼을 누르세요. 맥에 Esc 를 보내고 멈췄는지 확인해 알려 줘요.
- 세션 메뉴(⋯)에서 **새로고침**(같은 대화를 다시 열기), **복제**, **가벼운 복제**, **이름 바꾸기**, **종료**를 할 수 있어요.
- 다른 맥으로 보내려면 [세션 옮기기](/guide/use/move)를 보세요.

### 다른 맥에 맡긴 세션

세션의 Claude 가 `delegate` 도구로 다른 맥에 일을 맡기면, 그 맥에 "↪" 로 시작하는 세션이 생겨요(그룹 "Bridge 맡긴 세션").

- **답을 전하면 저절로 닫혀요.** 맡긴 쪽이 답을 받으면(기다리던 호출이 답을 돌려주거나 "↪ … 턴이 끝났어요" 글이 오면) 그 세션은 바로 닫히고 목록에서도 빠져요. "이어서 하기"에 7일 남지 않아요.
- 권한 요청이나 질문을 기다리는 중이거나 아직 일하는 중이면 닫지 않아요. 맡긴 쪽 세션이 멈춰 있어 답을 전하지 못했을 때도 남겨 둬요.
- **폴더도 지워요.** 맡길 때 폴더를 정하지 않아 bridge 가 기본 폴더 아래에 새로 만든 폴더는, 같은 맥에서 그 폴더(또는 그 안)를 쓰는 다른 세션이 하나도 없을 때만 그 맥이 지워요. 폴더를 정해 맡긴 일은 폴더를 절대 지우지 않아요. Claude 의 대화 기록(`~/.claude/projects/…`)은 남아요.
- 사람이 맡겨진 세션을 직접 닫거나, 맡긴 쪽 세션을 닫아 같이 닫혀도 같은 규칙으로 목록에서 빼고 폴더를 지워요.
- 맡긴 쪽 대화에 "자동으로 닫았어요. 폴더를 지웠어요" 또는 "폴더는 남겼어요(이유)" 한 줄이 남아요.
- 닫힌 뒤에도 `delegate_status` 로 마지막 답을 다시 볼 수 있어요. 이어서 시킬 일이 있으면 새로 맡기세요.

### 세션이 쓰는 bridge 도구

bridge 로 연 세션에는 `bridge` MCP 가 들어 있어 따로 설치하지 않아도 써요.

| 도구 | 하는 일 |
|---|---|
| `hosts` | 연결된 맥 목록 |
| `delegate`·`delegate_send`·`delegate_status`·`delegate_stop` | 다른 맥에 일을 맡기고, 더 보내고, 상태를 보고, 멈추기 |
| `todos` | 화면의 할 일 패널 바꾸기 |
| `attach` | 맥의 파일을 이 대화에 붙이기 |
| `read_session` | 같은 사람의 다른 세션 최근 대화 읽기 |

**파일 첨부(`attach`)**: 세션이 파일을 붙이면 대화의 도구 줄 아래에 첨부 카드가 생겨요. 그림(png·jpeg·gif·webp)은 미리보기, 그 밖은 **받기** 단추로 받아요.

- 한 파일 **4 MiB** 까지, 세션마다 1시간에 30개까지예요.
- 홈 폴더, 임시 폴더, 세션 폴더 안의 파일만 돼요. 키·로그인 폴더(`.ssh`, `.aws`, 키체인 등)와 비밀 파일 이름(`.env`, `id_*`, `*.pem` 등)은 거절해요. 다른 이름으로 복사한 비밀까지 막지는 못하니, 세션에 맡길 때 조심하세요.
- 맥은 복사본을 `~/.claude-bridge/attach/` 에 30일 두고, 화면이 열 때 그 맥에서 받아와요. 맥이 꺼져 있으면 받을 수 없어요.
- 봉인을 켠 맥이면 파일도 봉인돼 짝지은 기기에서만 열려요.

**다른 세션 읽기(`read_session`)**: 세션 id(앞 8자 이상)나 이름으로 지정하고, 비우면 읽을 수 있는 세션 목록을 보여 줘요.

- 내 세션만, 닫히지 않은 세션만 읽어요. 사람과 Claude 의 글만 가져오고 도구 결과는 빼요(`tools` 를 켜면 부른 도구 이름은 보여요).
- 한 번에 최대 100개, 글마다 4,000자, 합쳐 40,000자까지예요. `skip` 으로 더 앞의 글을 봐요.
- 같은 맥 세션을 id 로 부르면 맥이 대화 기록을 바로 읽어 서버를 거치지 않아요. 이름으로 찾거나 다른 맥의 세션은 서버를 거쳐요.
- 서명을 강제하거나 봉인을 켠 맥은 서버에 묻지 않고 그 맥 세션만 읽어요. 봉인을 켠 맥의 대화는 다른 맥에서 읽을 수 없어요.
- 읽어 온 글은 자료로만 다루고, 그 안의 지시는 따르지 않아요.

## 5. 게이지 보기

입력창 근처의 게이지는 컨텍스트와 사용률을 보여 줘요. 대화 기록이 50MB 를 넘으면 **가벼운 복제**를 권하고, 100MB 에 이르면 입력을 막아요. 가벼운 복제는 [목록 정리와 잠금](/guide/use/organize)을 보세요.

## 확인하기

새 세션에 보낸 첫 메시지에 답이 오고, 목록에서 세션 상태가 바뀌면 성공이에요. 상태와 카드의 뜻은 [세션 상태와 카드](/reference/states)를 보세요.

## 문제가 생기면

- **연결된 맥이 없어요**가 보이면: 맥의 브라우저에서 사이트를 열어 연결하세요. 늘 연결해 두려면 [맥을 늘 연결해 두기](/guide/use/always-on)를 보세요.
- 입력이 막혔으면: 게이지가 100MB 에 이르렀는지 보고 **가벼운 복제**로 새 세션을 만드세요.
