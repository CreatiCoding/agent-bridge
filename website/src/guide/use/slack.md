# Slack 플러그인

이 가이드를 마치면 세션을 Slack 전용 채널에서 이어서 다룰 수 있어요. 플러그인이 서버와 주고받는 방식은 [플러그인 API](/reference/plugin-api)를 보세요.

## 시작하기 전에

- Slack 워크스페이스에 앱을 만들고 설치할 권한이 있어야 해요.
- Slack 플러그인은 [Slack Socket Mode](https://api.slack.com/apis/socket-mode) 로 붙어요. 서버에 들어오는 주소를 따로 열 필요가 없어요.
- 토큰은 두 가지가 필요해요. **Bot 토큰**은 `xoxb-` 로, **App 토큰**은 `xapp-` 로 시작해요.
- 한 세션은 한 번에 한 곳(Agent Bridge 또는 Slack)에서만 작업해요.

## 1. 설정 창 열기

**설정** → **플러그인**에서 Slack 의 **추가**(이미 있으면 **설정**)를 누르세요. 창에 토큰 칸과 1~7단계 안내가 보여요.

::: tip AI 에게 맡기기
**가이드** 화면의 **Slack 에서도 쓰기** 단계에 **프롬프트 복사**가 있어요. 이 프롬프트를 브라우저를 다루는 AI 에게 붙여 넣으면 1~4단계를 대신 해요. 토큰 복사만은 하지 않으니 토큰은 직접 붙여 넣으세요.
:::

## 2. Slack 앱 만들기

1. 안내 1단계의 **매니페스트 채운 새 앱 창 열기**를 누르세요.
2. 워크스페이스를 고르고 **Next** → **Create** 를 누르세요. 권한과 Socket Mode 설정은 매니페스트에 다 들어 있어요.

창이 비어 있으면 **From a manifest** 를 고르고, **앱 매니페스트 복사**로 복사한 내용을 JSON 탭에 붙여 넣으세요.

## 3. 토큰 두 개 넣기

1. Slack 앱 설정의 **Install App** → **Install to Workspace** → 허용을 누르세요.
2. **Bot User OAuth Token**(`xoxb-…`)을 복사해 **Bot 토큰** 칸에 넣으세요.
3. **Basic Information** → **App-Level Tokens** → **Generate Token and Scopes** 를 누르세요. 이름은 아무거나(예: `socket`) 적고, **Add Scope** 에서 `connections:write` 를 고르고 **Generate** 를 누르세요.
4. 나온 토큰(`xapp-…`)을 **App 토큰 (Socket Mode)** 칸에 넣으세요.

::: warning 주의
토큰은 비밀값이에요. 채팅이나 문서에 붙여 넣지 말고 설정 칸에만 넣으세요.
:::

## 4. 전용 채널 만들고 켜기

1. Slack 에서 Agent Bridge 만 쓰는 채널을 만드세요. 혼자 쓰는 비공개 채널을 권해요. 채널 맨 위에 쓴 글은 모두 새 세션이 되니 다른 대화가 있는 채널은 피하세요.
2. 그 채널에 봇을 부르세요.

   ```text [Slack]
   /invite @claude-bridge
   ```

3. 설정 창의 **전용 채널** 옆 **채널 고르기**를 눌러 그 채널을 고르세요.
4. **저장하고 켜기**를 누르세요.

## 5. 내 Slack 계정 연결하기

1. 전용 채널에 아무 글이나 한 번 쓰세요.
2. 봇이 나에게만 보이는 연결 링크를 줘요. 링크는 10분 동안 쓸 수 있어요.
3. Agent Bridge 에 로그인한 브라우저에서 링크를 열고, 확인 폼에서 연결을 누르세요.

링크를 열지 않은 Slack 계정은 채널에 있어도 세션을 조작할 수 없어요.

## 6. 세션을 Slack 으로 옮기기

1. 세션 메뉴(⋯)에서 **Slack 으로 옮기기**를 누르세요.
2. 전용 채널에 그 세션의 스레드가 생겨요. 스레드에서 이어서 작업하세요.

Slack 에서 작업하는 동안 Agent Bridge 화면은 읽기만 돼요. **이 세션은 Slack 에서 작업 중이에요** 배너가 보여요. 돌아오려면 스레드의 **브릿지로 옮기기**나 세션 메뉴의 **브릿지로 가져오기**를 누르세요. 어느 쪽에서 나눈 대화든 Agent Bridge 세션 화면에 모두 남아요.

## 확인하기

- 설정 창의 상태가 **켜짐**이면 플러그인이 붙은 거예요.
- **가이드** 화면에 **켜짐 · 내 Slack 계정 연결됨**이 보이면 계정 연결까지 끝난 거예요.
- 전용 채널 맨 위에 글을 써서 새 세션이 뜨면 성공이에요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "토큰을 받지 않았어요" | 두 토큰이 서로 바뀌지 않았는지 보세요. `xoxb-` 는 Bot, `xapp-` 는 App 이에요 |
| **채널 고르기**가 권한이 없다고 해요 | 예전 매니페스트로 만든 앱이에요. **OAuth & Permissions** 에서 `channels:read`, `groups:read` 를 더하고 앱을 다시 설치하세요 |
| 켜짐인데 반응이 없어요 | 봇이 그 채널에 들어와 있는지 보세요 |
| 새 세션이 안 떠요 | 맥의 에이전트가 연결돼 있어야 해요 |
| **Slack 으로 옮기기**가 흐려요 | 플러그인이 꺼져 있거나 잠긴 세션이에요. 잠긴 세션은 Slack 으로 옮길 수 없어요 |
