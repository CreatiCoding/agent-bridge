# 맥을 늘 연결해 두기

이 가이드를 마치면 자리를 비워도 맥이 서버와 계속 이어져 있어요. 맥이 서버와 어떻게 이어지는지는 [구성과 연결](/guide/concepts/architecture)을 보세요.

맥이 끊기는 까닭은 두 가지예요. 맥이 잠들거나, 맥과 서버를 잇는 브라우저 탭(**연동 페이지**)이 닫히는 거예요. 세 가지 방법으로 막을 수 있어요.

| 방법 | 막는 것 | 필요한 것 | 알아 둘 것 |
|---|---|---|---|
| **잠자기 막기** | 쓰지 않을 때 맥이 잠드는 것 | 없음 | 화면은 꺼질 수 있어요. 맥북 덮개를 닫으면 잠들어요 |
| **덮개를 닫아도 켜 두기** | 맥북 덮개를 닫아 잠드는 것 | 터미널에서 한 번 `awake setup`(관리자 비밀번호) | 닫은 채 가방에 넣으면 뜨거워질 수 있어요 |
| **헤드리스 연동 모드** | 연동 페이지 탭이 닫혀 끊기는 것 | 맥에 Chrome | 메모리를 수백 MB 써요. 에이전트가 바깥과 연결하게 돼요 |

세 가지 모두 에이전트가 꺼지면 원래대로 돌아가요. 선택은 그 맥의 `~/.claude-bridge/agent.json` 에 남아요.

## 시작하기 전에

- 맥이 지금 연결돼 있어야 해요. 이 설정은 **맥이 연결돼 있을 때 바꿀 수 있어요**.
- 맥이 잠들면 세션이 멈추고 웹과 끊겨요. 끊긴 맥의 세션은 다른 맥으로 옮길 수도 없어요. 자세한 내용은 [세션 옮기기](/guide/use/move#옮길-수-없을-때)를 보세요.

## 1. 잠자기 막기 켜기

1. **기기** 화면에서 맥을 고르세요.
2. **잠자기 막기** 스위치를 켜세요.

**잠자기를 막았어요** 알림이 뜨면 돼요. 에이전트가 켜져 있는 동안 `caffeinate -i -w` 로 맥이 잠들지 않게 해요. 권한은 필요 없어요.

## 2. 덮개를 닫아도 켜 두기 (맥북)

이 방법은 `pmset -a disablesleep 1` 을 써서 관리자 권한이 필요해요. 처음 한 번만 그 맥의 터미널에서 실행하세요.

```sh [터미널]
node ~/.claude-bridge/agent.mjs awake setup
```

이 명령은 `pmset -a disablesleep 0`·`1` 두 명령만 비밀번호 없이 허용하는 `/etc/sudoers.d/claude-bridge-pmset` 를 만들어요. 그다음 사이트에서 켜세요.

1. **기기** 화면에서 맥을 고르세요.
2. **덮개를 닫아도 켜 두기** 스위치를 켜세요.

**덮개를 닫아도 켜 둬요** 알림이 뜨면 돼요. 덮개를 닫으면 화면은 꺼지지만 맥은 잠들지 않아요.

| 명령 | 하는 일 |
|---|---|
| `node ~/.claude-bridge/agent.mjs awake status` | 설정돼 있는지 보여 줘요 |
| `node ~/.claude-bridge/agent.mjs awake remove` | 만든 규칙을 지워요 |

## 3. 헤드리스 연동 모드 켜기

보통은 맥의 Chrome 에 사이트 탭이 열려 있어야 맥과 서버가 이어져요. **헤드리스 연동 모드**를 켜면 에이전트가 화면 없는 Chrome 을 띄워 연동 페이지를 늘 열어 둬요.

1. **기기** 화면에서 맥을 고르세요.
2. **헤드리스 연동 모드** 스위치를 켜세요.

**헤드리스 연동 모드를 켰어요. 잠시 뒤 연결돼요** 알림이 떠요. 켤 때 서버가 일회용 로그인 코드(5분, 한 번)를 에이전트에 건네고, 헤드리스 Chrome 이 그 코드로 로그인해요. 로그인은 전용 프로필 `~/.claude-bridge/browser` 에 남아요.

::: warning 바깥 연결에 대해
Agent Bridge 의 에이전트는 원래 혼자서 바깥과 연결하지 않아요. 이 모드를 켠 맥에서는 그렇지 않아요. 에이전트가 띄운 브라우저가 서버에 연결해요. 또 프로필 폴더가 곧 로그인 정보예요. 자세한 내용은 [보안 모델](/guide/concepts/security)을 보세요.
:::

## 확인하기

**기기** 화면의 **에이전트 상태**에서 연동, 헤드리스 연동 모드, 잠자기 막기, 덮개 항목이 정상으로 보이면 성공이에요. 맥의 브라우저 탭을 모두 닫고 몇 분 뒤 폰에서 세션에 글을 보내 보세요. 답이 오면 헤드리스 연동 모드가 일하고 있는 거예요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 덮개 스위치가 켜지지 않아요 | 그 맥에서 `awake status` 를 실행하세요. 설정돼 있지 않다고 나오면 `awake setup` 을 하세요 |
| **Chrome 이 없어요** | 헤드리스 연동 모드는 맥의 Chrome 이 필요해요. Chrome 을 깔아 주세요 |
| 잠자기 막기가 꺼져 보여요 | 에이전트가 1분마다 스스로 살펴 꺼진 `caffeinate` 를 다시 띄워요. 계속 꺼져 보이면 **에이전트 상태**에 나온 할 일을 따르세요 |
| 맥이 계속 끊겨요 | [문제 해결](/guide/operate/troubleshooting)을 보세요 |
