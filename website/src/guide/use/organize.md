# 목록 정리와 잠금

이 가이드를 마치면 세션을 그룹으로 묶고, 쓰지 않는 세션을 쉬게 하고, 남에게 보이면 안 되는 세션을 잠글 수 있어요. 잠금이 무엇을 지키는지는 [보안 모델](/guide/concepts/security)을 보세요.

## 시작하기 전에

- 세션이 몇 개 있어야 해요. 세션을 띄우는 방법은 [폰에서 세션 다루기](/guide/use/sessions)를 보세요.
- 그룹, 휴면, 잠금은 계정에 저장돼서 모든 기기에서 같게 보여요.

## 1. 그룹으로 묶기

**그룹**은 세션을 담는 폴더예요. 그룹 안에 그룹을 둘 수 있고, 3단계까지 들어가요.

1. 세션 메뉴(⋯)에서 **그룹** → **새 그룹에 넣기…** 를 누르세요.
2. **그룹 이름**을 적으세요.

이미 있는 그룹에 넣으려면 같은 메뉴에서 그룹을 고르세요. 빼려면 **그룹에서 빼기**를 누르세요. 목록의 행을 끌어서 순서를 바꿀 수도 있어요.

그룹 줄의 **그룹 ⋯** 메뉴에는 **그룹 비우기**와 **그룹 지우기**가 있어요. 그룹을 지워도 세션은 지워지지 않아요.

## 2. 휴면으로 쉬게 하기

**휴면**은 지금 쓰지 않는 세션을 그룹 목록에서 숨기는 일이에요. 세션은 끝나지 않아서 언제든 다시 열 수 있어요.

- 세션 메뉴(⋯)에서 **휴면**을 누르세요. 폰에서는 목록의 행을 왼쪽으로 144px 밀어도 **휴면**이 나와요.
- 다시 쓰려면 그룹 메뉴의 **휴면 세션 n개**에서 세션을 고르거나 검색으로 찾아 여세요. 휴면 세션은 열면 깨어나요. 세션 메뉴의 **휴면 풀기**로도 깨울 수 있어요.

행을 밀면 **종료**도 함께 나와요. 끝난 세션을 밀면 **이어서 열기**와 지우기가 나와요.

## 3. 가벼운 복제로 새로 시작하기

대화가 길어지면 응답이 느려지고 비용이 커져요. **가벼운 복제**는 지금까지의 내용을 `SESSION.md` 로 줄여 새 세션을 시작해요.

1. 세션 메뉴(⋯)에서 **가벼운 복제**를 누르세요.
2. 새 세션이 열리면 거기서 이어서 일하세요.

원본 세션은 휴면이 돼요. 넘겨주는 요약의 크기는 컨텍스트 창의 1/10 이고, 20KB 에서 100KB 사이로 맞춰요.

::: tip 언제 쓰나요?
대화 기록이 50MB 를 넘으면 게이지가 가벼운 복제를 권해요. 100MB 에 이르면 입력이 막히니 그 전에 하세요.
:::

## 4. 세션 잠그기

**잠금**은 세션을 비밀번호로 가리는 일이에요. 잠긴 세션은 목록에 이름과 상태만 보여요. 대화, 쓰는 중인 글, 터미널 화면, 알림 내용, 플러그인으로 아무것도 나가지 않아요.

1. 세션 메뉴(⋯)에서 **잠그기**를 누르세요.
2. **세션 잠그기** 창에 **비밀번호**를 4자 이상 넣고 **다음**을 누르세요.
3. **비밀번호 확인**에 한 번 더 넣고 **잠그기**를 누르세요.

잠긴 세션을 열면 **잠긴 세션이에요**와 함께 비밀번호를 물어요. 비밀번호로 연 탭에서만 내용이 보여요. 탭을 닫거나, 연 지 12시간이 지나거나, 배포로 서버가 다시 켜지면 다시 물어요.

| 메뉴 | 하는 일 |
|---|---|
| **잠금** → **이 탭에서 다시 잠그기** | 이 탭에서 연 잠금을 다시 걸어요 |
| **잠금** → **잠금 없애기…** | 비밀번호를 넣으면 잠금을 없애요. 모든 기기에서 다시 내용이 보여요 |

::: danger 비밀번호를 잊으면
잠금을 풀 방법이 없어요. 서버에는 비밀번호를 늘린 해시만 남아요.
:::

비밀번호는 60초에 10번까지 시도할 수 있어요. Slack 에서 작업 중인 세션은 잠글 수 없고, 잠긴 세션은 Slack 으로 옮길 수 없어요.

## 확인하기

- 그룹: 목록에서 세션이 그룹 아래에 들여 보이면 성공이에요.
- 휴면: 세션이 그룹 목록에서 사라지고 그룹 메뉴의 **휴면 세션 n개**에 보이면 성공이에요.
- 잠금: 다른 기기에서 그 세션을 열었을 때 비밀번호를 물으면 성공이에요.

## 문제가 생기면

- 잠긴 세션의 대화가 이 기기에서 바로 그려지지 않아요: 정상이에요. 이 브라우저의 대화 캐시는 최근 30개 세션, 세션마다 3,000 이벤트를 남기지만 잠긴 세션은 남기지 않아요.
- 비밀번호를 여러 번 틀려 막혔으면: 1분 기다린 뒤 다시 넣으세요.
