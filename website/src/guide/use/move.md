# 세션 옮기기

이 가이드를 마치면 하던 세션을 다른 맥에서 같은 대화로 이어서 열 수 있어요. 옮기기가 안에서 어떻게 이뤄지는지는 [옮기기와 작업 폴더 싱크](/guide/concepts/sync)를 보세요.

## 시작하기 전에

- **호스트(맥)** 두 대가 같은 계정으로 연결돼 있어야 해요. 세션을 지금 돌리는 맥이 **보내는 맥**, 새로 열 맥이 **받는 맥**이에요.
- **옮기기**는 보내는 맥에서 대화와 기록을 받아 받는 맥에서 `claude --resume` 으로 여는 일이에요. 서버는 대화 사본을 갖지 않아요. 그래서 **보내는 맥이 연결돼 있어야** 옮길 수 있어요.
- 작업 폴더는 통째로 옮기지 않아요. git 저장소면 브랜치와 커밋을, 아니면 `SESSION.md`·`AGENTS.md`·`CLAUDE.md` 를 받는 맥에 맞춰 줘요.

## 1. 세션을 쉬게 하기

옮기기는 세션이 쉬고 있을 때만 돼요.

- 턴이 끝날 때까지 기다리거나 **중단 (Esc)** 을 누르세요.
- 답을 기다리는 확인 창이 있으면 먼저 답하세요.

## 2. 받는 맥 고르기

1. 세션 메뉴(⋯)에서 **다른 맥으로 옮기기**를 누르세요.
2. **옮기기** 창에서 받는 맥(**○○(으)로 옮기기**)을 고르세요. 각 맥 아래에 **연결됨** 또는 **연결 끊김 — 붙으면 옮길 수 있어요**가 보여요.
3. 받는 맥에 Claude 계정이 여럿이면 어느 계정에서 열지 고르세요.

## 3. 옮겨지기를 기다리기

**○○ → ○○ 로 옮기는 중이에요…** 알림이 뜨고 세션은 **옮기는 중** 상태가 돼요. 이 동안 다음이 차례로 일어나요.

1. 보내는 맥이 마지막 싱크를 해요.
2. 받는 맥이 대화를 받아 같은 대화로 열어요.
3. 열린 것을 확인한 뒤 보내는 맥이 세션을 내려놓아요.

받는 맥에서 열지 못하면 세션은 원래 맥에 그대로 남아요.

## 확인하기

세 가지를 차례로 보세요.

1. **받는 맥에서 세션이 열렸는지.** **○○(으)로 옮겼어요** 알림이 뜨고 세션 줄의 맥 이름이 받는 맥으로 바뀌면 성공이에요. 대화에도 옮기기가 한 줄로 남아요. 세션을 열어 이전 대화가 이어져 보이는지도 보세요.
2. **작업 폴더의 브랜치와 커밋이 맞는지.** git 저장소에서 작업했다면 두 맥에서 같은 명령을 실행해 결과를 비교하세요. 브랜치 이름과 마지막 커밋이 같으면 코드도 맞춰진 거예요.

   ```sh [터미널]
   git -C WORKDIR branch --show-current
   git -C WORKDIR log -1 --oneline
   ```

   `WORKDIR` 는 세션의 작업 폴더 경로예요(예: `~/works/my-app`). 알림에 **확인할 것**이 붙어 있으면 그 내용(예: 커밋 안 된 변경, 원격에 푸시되지 않음)을 받는 맥에서 살펴보세요.
3. **보내는 맥이 세션을 내려놓았는지.** 보내는 맥은 열기가 성공한 뒤에 그 세션의 터미널을 끝내고 목록에서 빼요. 목록에 같은 세션이 보내는 맥 이름으로 따로 남아 있지 않으면 돼요. 대화 파일과 작업 폴더는 보내는 맥에도 그대로 남아요.

## 옮길 수 없을 때

메뉴가 흐리게 보이거나 옮기기가 거절되면 아래 표에서 이유를 찾으세요.

| 보이는 말 | 이유 | 할 일 |
|---|---|---|
| **다른 맥으로 옮기기 (다른 맥 없음)** | 연결된 다른 맥이 없어요 | 받는 맥의 브라우저에서 사이트를 열어 연결하세요 |
| 보내는 맥 이 연결돼 있지 않아 옮길 수 없어요 | 서버에 대화 사본이 없어 보내는 맥에서만 대화를 받을 수 있어요 | 그 맥을 켜고 연동한 뒤 다시 하세요 |
| 받는 호스트가 연결돼 있지 않습니다 | 받는 맥이 끊겼어요 | 받는 맥을 연결하세요 |
| 작업 중입니다. 턴이 끝난 뒤에 옮겨 주세요 | 턴이 도는 중이에요 | 끝나기를 기다리거나 중단하세요 |
| 응답을 기다리는 확인 창이 있습니다 | 카드에 답하지 않았어요 | 카드에 답하세요 |
| 보내는 맥 의 에이전트가 업데이트되면 옮길 수 있어요 | 보내는 맥의 에이전트가 오래됐어요 | 에이전트 업데이트를 기다리거나 맥에서 다시 시작하세요 |
| 그 Claude 계정은 로그인돼 있지 않습니다 | 받는 맥의 그 계정이 로그아웃 상태예요 | **설정** → **Claude 계정**에서 로그인하세요 |

::: warning 주의
보내는 맥이 꺼져 있으면 다른 맥에서 이어 갈 방법이 없어요. 오래 자리를 비울 맥이라면 [맥을 늘 연결해 두기](/guide/use/always-on)로 연결을 지켜 두세요.
:::

## 돌아가기 배너

예전 판에서 보내는 맥이 끊긴 채 옮겨진 세션에는 **돌아가기** 배너가 뜰 수 있어요. 원래 맥이 다시 연결되면 "원래 맥 ○○ 이(가) 돌아왔어요"라고 알려 줘요.

- **○○ 로 돌아가기**: 원래 맥의 이 세션을 지금 대화로 덮어쓴 뒤 옮겨요. 덮어쓰기 전 사본은 그 맥의 `~/.claude-bridge/overwritten/` 에 남아요.
- **여기서 계속**: 배너를 닫고 지금 맥에서 이어 가요.

## 문제가 생기면

- **보내는 호스트에서 마지막 싱크를 하지 못했습니다**: 보내는 맥의 연결을 확인하고 다시 하세요.
- **받는 호스트에서 열지 못했습니다**: 세션은 원래 맥에 남아 있어요. 받는 맥의 로그를 보세요. 경로는 [맥의 파일과 경로](/reference/files)에 있어요.
