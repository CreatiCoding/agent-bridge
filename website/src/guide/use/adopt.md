# 맥의 대화 가져오기

이 가이드를 마치면 맥의 터미널에서 쓰던 Claude Code 대화를 폰에서 이어 갈 수 있어요. 이 일을 **가져오기**라고 해요. 세션이 만들어지는 다른 길은 [세션의 일생](/guide/concepts/sessions)을 보세요.

## 시작하기 전에

- 대화가 있는 **호스트(맥)** 가 연결돼 있어야 해요.
- 가져올 수 있는 대화는 그 맥의 Claude Code 대화 가운데 Agent Bridge 세션이 아닌 것이에요. 터미널이나 다른 도구에서 시작한 대화가 여기에 들어가요.
- 가져온 대화는 원래 폴더에서 `claude --resume` 으로 열려요. 같은 대화가 그대로 이어져요.

## 1. 대화 목록 열기

1. 목록에서 **새 세션**을 누르세요.
2. **기기**에서 대화가 있는 맥을 고르세요.
3. **맥의 대화 이어 가기**를 누르세요.

그 맥의 대화가 목록으로 보여요. 위의 **제목·내용·폴더 검색** 칸에 낱말을 넣으면 걸러져요.

## 2. 대화 고르기

이어 갈 대화를 누르세요. 여러 개를 골라 한 번에 가져올 수도 있어요. 맥을 바꿔 가며 쓰던 대화를 한꺼번에 옮겨 올 때 편해요.

각 대화에는 제목과 폴더가 함께 보여요. 같은 폴더에 대화가 여럿이면 제목과 내용으로 구별하세요.

목록에는 이런 표시가 붙을 수 있어요.

| 표시 | 뜻 |
|---|---|
| **쓰는 중** | 1분 안에 기록이 쓰인 대화예요. 맥의 다른 곳에서 아직 쓰고 있을 수 있어요 |
| **폴더 없음** | 대화를 시작한 폴더가 지금 맥에 없어요 |

## 3. 이어 가기

**이어 가기**를 누르세요. 고른 대화마다 세션이 하나씩 생겨요.

**쓰는 중** 대화를 골랐으면 **이 대화를 bridge 에서 이어 갈까요?** 라고 먼저 물어요. 같은 대화를 두 곳에서 쓰면 기록이 엇갈려요. 맥의 터미널에서 그 대화를 끝낸 뒤 이어 가세요.

## 4. 주소로 미리 골라 열기 (선택)

자주 가져오는 대화가 있으면 대화 id 를 주소에 넣어 미리 고른 채 열 수 있어요.

```text [주소]
SITE/new?adopt=ID,ID
```

- `SITE` 는 서버 주소예요(예: `https://bridge.example.com`).
- `ID` 는 Claude Code 대화 id(36자 UUID)예요. 맥의 `~/.claude/projects/` 아래 `.jsonl` 파일 이름과 같아요. 쉼표로 여러 개를 이어 쓰고, 꼴이 맞지 않는 id 는 무시돼요.

이 주소는 앱이 만들어 주지 않아요. 직접 적어서 북마크로 두세요.

## 5. 가져온 세션 다루기

가져온 대화는 이제 보통 세션과 같아요. 폰에서 글을 보내고, 확인 창에 답하고, 그룹에 넣거나 잠글 수 있어요. 다른 맥으로 옮기는 것도 같은 절차예요. 자세한 내용은 [세션 옮기기](/guide/use/move)를 보세요.

맥의 터미널에서 같은 대화를 다시 열지는 마세요. 두 곳이 같은 기록에 쓰게 돼요. 맥 앞에 앉아서 이어 가고 싶으면 그 맥의 브라우저로 사이트를 열어 같은 세션을 다루세요.

## 확인하기

목록에 가져온 대화가 새 세션으로 보이고, 열었을 때 예전 대화가 그대로 이어져 있으면 성공이에요. 메시지를 하나 보내 답이 오는지도 보세요.

## 문제가 생기면

- **이어 갈 대화가 없어요**: 그 맥에 Agent Bridge 세션이 아닌 대화가 없어요. 맥에서 `claude` 로 대화를 한 번 시작했는지 확인하세요.
- **대화 목록을 읽지 못했어요**: 맥의 연결이 끊겼을 수 있어요. 기기를 다시 고르거나 맥을 연동하세요.
- 기록이 엇갈려 보이면: 같은 대화를 맥의 터미널에서도 쓰고 있는지 확인하고 한쪽을 끝내세요.
