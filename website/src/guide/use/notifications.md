# 알림과 웹 푸시

이 가이드를 마치면 세션이 답을 기다릴 때 폰이 잠겨 있어도 알림을 받을 수 있어요. 알림이 담는 내용과 담지 않는 내용은 [보안 모델](/guide/concepts/security)을 보세요.

## 시작하기 전에

- 사이트에 로그인할 수 있어야 해요.
- iPhone·iPad 는 사이트를 **홈 화면에 추가**한 뒤에만 웹 푸시를 받아요. 브라우저 탭에서는 알림 센터만 쓸 수 있어요.
- **웹 푸시**는 브라우저가 꺼져 있어도 기기로 오는 알림이에요. 서버에 푸시 키가 있어야 해요. 서버 쪽 준비는 [서버 올리기](/guide/operate/self-host)를 보세요.

## 알림이 생기는 때

| 무엇 | 언제 | 웹 푸시 |
|---|---|---|
| 권한 요청 | Claude 가 도구를 쓰려고 허락을 묻는데 그 대화를 보고 있지 않을 때 | 늘 보내요 |
| 그 밖의 카드 알림 | 질문, 플랜 승인 같은 확인 창이 떴는데 그 대화를 보고 있지 않을 때 | 보내요 |
| 다시 알리기 | 카드에 5분 동안 답이 없을 때. 권한 요청은 10분에도 한 번 더 | 보내요 |
| 작업 끝 | 백그라운드 작업이 끝났을 때 | 보내지 않아요. 알림 센터에만 남아요 |

푸시는 사람이 답해야 세션이 움직이는 때를 위해 둬요. 그래서 작업이 끝난 소식으로는 폰을 울리지 않아요.

권한 요청 알림은 어느 세션, 어느 맥, 무슨 호출인지 담아요. 예를 들어 제목이 `🔐 권한 요청 · 배포`, 내용이 `iMac · Bash: git push origin main` 이에요. 다시 알리기는 내용 앞에 `⏰ 5분째 기다리는 중` 이 붙어요.

카드에 답하면 그 카드의 알림은 저절로 거둬져요. 그래서 알림 센터에는 아직 답하지 않은 카드와 지난 작업 소식만 남아요. 다시 알리기는 같은 카드에 대해 정해진 횟수만 오고, 그 뒤에는 더 울리지 않아요.

## 1. 폰을 홈 화면에 추가하기 (iPhone·iPad)

1. Safari 로 사이트를 여세요.
2. 공유 버튼을 누르고 **홈 화면에 추가**를 고르세요.
3. 홈 화면에 생긴 아이콘으로 사이트를 다시 여세요.

Android 의 Chrome 은 이 단계 없이 다음으로 넘어가도 돼요.

## 2. 웹 푸시 켜기

1. **설정** → **이 기기**로 가세요.
2. **이 기기로 웹 푸시** 스위치를 켜세요.
3. 브라우저가 알림을 허용할지 물으면 **허용**을 누르세요.

웹 푸시는 기기마다 켜요. 폰과 노트북에서 모두 받으려면 각 기기에서 켜세요. 끄려면 같은 스위치를 끄세요. 다른 기기의 구독은 그대로 남아요.

## 3. 알림 센터 보기

**알림**을 누르면 지난 알림이 보여요. **지우기**로 목록을 비울 수 있어요.

알림 센터는 최근 30개를 남기고, 30일이 지난 알림은 지워요. 세션을 지우면 그 세션의 알림도 함께 지워져요.

## 4. 알림에서 바로 허용·거부하기

권한 요청 푸시에는 **허용**·**거부** 버튼이 붙어요. 세션을 열지 않고 알림에서 바로 답할 수 있어요.

1. 권한 요청 알림이 오면 **허용** 이나 **거부** 를 누르세요.
2. 답이 들어가면 알림이 **허용했어요** 나 **거부했어요** 로 바뀌어요.
3. 답하지 못하면(로그인이 풀렸거나 세션이 없거나) 세션 화면이 열려요. 거기서 답하세요.

알림 본문을 누르면 지금처럼 세션 화면이 열려요.

::: details 버튼이 없거나 답이 안 들어가는 때
- Safari 와 iPhone·iPad 의 홈 화면 앱은 알림 버튼을 그리지 않아요. 알림을 누르면 세션이 열려요.
- 버튼은 **허용**(한 번 허용)과 **거부** 둘뿐이에요. 항상 허용, 이 세션 동안 허용은 세션 화면의 카드에서 고르세요.
- [잠긴 세션](/guide/use/organize#4-세션-잠그기)의 알림에는 버튼이 없어요. 답하려면 잠금을 풀어야 해요.
- 카드에 한 번 허용·거부 선택지가 없으면 버튼이 붙지 않아요.
- 맥은 그 카드가 아직 열려 있을 때만 답을 눌러요. 그사이 카드가 닫혔다면 다른 확인 창에 잘못 답하지 않고, 세션 화면에 `이 선택은 이미 끝났습니다` 가 떠요.
- 서버에 [before 훅](/guide/operate/hooks#예-2-위험한-액션-전에-검사하기)이 있으면 알림 버튼으로 한 답도 같은 검사를 거쳐요.
:::

## 확인하기

폰 화면을 끄고 맥의 세션이 권한을 묻게 해 보세요. 예를 들어 첫 메시지로 파일을 하나 만들어 달라고 하세요. 폰에 알림이 오고, 알림 센터에 같은 알림이 보이면 성공이에요.

::: tip 바로 오지 않는 이유
- 그 대화를 화면에 띄워 두고 있으면 알림을 만들지 않아요.
- 권한 요청이 아닌 알림은, 45초 안에 Agent Bridge 화면을 봤다면 푸시하지 않아요. 이미 보고 있는 사람에게 겹쳐 울리지 않으려는 거예요.
- 권한 요청은 책상의 탭이 앞에 떠 있어도 늘 푸시해요.

시험할 때는 그 대화를 닫고 화면을 끈 뒤 1분쯤 기다리세요.
:::

## 푸시에 담기는 것

웹 푸시에는 내용이 실리지 않아요. 푸시는 기기를 깨우기만 하고, 깨어난 사이트가 서버에 알림 내용을 물어서 보여 줘요. 그래서 푸시 서비스(Apple·Google)는 대화 내용을 보지 못해요.

[잠긴 세션](/guide/use/organize#4-세션-잠그기)의 알림은 제목이 **잠긴 세션**, 글이 **확인할 것이 있어요**로만 보여요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| **이 브라우저는 웹 푸시를 못 받아요 (폰은 홈 화면에 추가한 뒤)** | iPhone·iPad 면 1단계를 하세요. 그 밖이면 웹 푸시를 지원하는 브라우저로 여세요 |
| **서버에 푸시 키가 없어서 아직 알림이 오지 않아요** | 서버 운영자에게 알리세요. 서버의 데이터 폴더에 푸시 키가 만들어져야 해요 |
| 스위치는 켜졌는데 알림이 안 와요 | 기기 설정에서 사이트(또는 홈 화면 앱)의 알림이 허용돼 있는지 보세요. 45초 규칙도 확인하세요 |
